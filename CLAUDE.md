# m/design — правила проекта

Сайт-портфолио. Vue 3 + Vite + vue-router, `vite-ssg` для пререндера, GSAP для анимаций. Свой CSS на кастомных свойствах. Без Tailwind, без UI-библиотек, без Pinia.

Стиль — премиальный минимализм по образцу eleken.co. Все значения ниже сняты замерами с референса, а не придуманы. Не меняй их без явной просьбы.

---

## Главное правило

**Единственный источник значений — `src/styles/tokens.css` и `src/styles/base.css`.**

В компонентах не должно быть ни одного захардкоженного цвета, размера шрифта, радиуса или отступа. Если нужного значения нет — добавь токен, а не число в `<style scoped>`.

Особенно: **не переопределяй в компонентах типографику из `base.css`**. Классы `h1`, `h2`, `h3` уже настроены глобально вместе с адаптивом. Локальный `font-size` или `font-weight` на заголовке — ошибка, а не решение.

---

## Пять принципов стиля

Нарушение любого разваливает визуал, даже если токены применены верно.

1. **Фон не белый.** Тёплый беж `#F6F4F2`. Белый — только карточки поверх него
2. **Чёрный не чёрный.** `#1D1E22`. Чистый `#000` не используется нигде
3. **Отрицательный трекинг на заголовках.** −1.5px на 52px, −0.64px на 32px
4. **Воздуха больше, чем кажется нужным.** Между секциями 300px, не 80
5. **Акцент занимает около 1% площади.** Только иконки и мелкие отметки. Никаких оранжевых блоков и кнопок

   Исключение, согласовано владельцем: иконки инструментов в пилюлях стека (`StackMarquee`) — в фирменных цветах брендов. Только там; градиенты внутри логотипов заменены сплошным цветом.

Плюс: теней практически нет, градиентов нет, декоративных фигур нет.

---

## Запрещено

- **Заглавные буквы с положительной разрядкой.** `text-transform: uppercase` вместе с `letter-spacing: .02em` и подобным. Это язык техностартапов, он не сочетается с Gilroy и бежевым фоном. Строчные везде
- Положительный `letter-spacing` в принципе. На заголовках он отрицательный, на тексте и интерфейсе — ноль
- Вес шрифта 700 на заголовках. В системе 500, на отдельных элементах 600
- Тени, градиенты, свечения, стеклянные эффекты
- Обводка вместо заливки у пилюль
- `<a href>` для внутренних переходов — только `<RouterLink>`
- Карусели там, где помещается сетка
- Цифры и метрики, которых нет в реальности

## Типографика

Настроена в `base.css`, включая брейкпоинты. Используй классы, не переопределяй.

| Класс | Размер | LH | Трекинг | Вес | margin-bottom |
|---|---|---|---|---|---|
| `.h1` | 52px | 1.115 | −1.5px | 500 | 20px |
| `.h2` | 32px | 1.25 | −0.64px | 500 | 40px |
| `.h3` | 18px | 1.33 | −0.18px | 500 | 8px |
| body, `p` | 15px | 25px | 0 | 400 | 0 |
| `.ui` | 13px | 20px | 0 | 500 | — |
| `.caption` | 12px | 28px | 0 | 400 | — |

Заголовки — Gilroy (`--f-head`), всё остальное — Inter (`--f-body`).

Брейкпоинты: **1550 / 1279 / 1023 / 767 / 479**.

Ширины текстовых колонок: параграф `--measure-paragraph` 620px, заголовок секции `--measure-heading` 468px, заголовок в карточке `--measure-card-head` 434px. Строку длиннее 620px не допускаем.

### Контейнер и гаттер

`--container`/`--gutter` меняются той же шкалой брейкпоинтов, каскадом сверху вниз — при равной специфичности побеждает правило ниже по файлу, поэтому порядок в `tokens.css` обязателен.

| Ширина экрана | `--container` | `--gutter` |
|---|---|---|
| ≥1550px | 1550px | 60px |
| ≤1549px | 1320px | 40px |
| ≤1279px | 1120px | 32px |
| ≤1023px | 100% | 24px |
| ≤767px | 100% | 20px |
| ≤479px | 100% | 16px |

## Цвет

Роли важнее значений. Бери по смыслу, не по совпадению оттенка.

- `--bg` — фон страницы, `--bg-2` секции и вторичная кнопка, `--bg-3` пилюли и разделители, `--bg-4` вложенные блоки
- `--ink` — заголовки, тёмные секции, primary-кнопка; `--ink-hover` её ховер
- `--text` — **основной текст на странице**, именно он доминирует, а не `--ink`
- `--text-2`, `--text-3` — вторичный и подписи
- `--accent` — слэш в логотипе, номера этапов, мелкие отметки. Ничего крупного
- `--border`, `--border-soft` — линии

## Вертикальный ритм

Задаётся **только снизу**:

```css
section { padding: 0 0 var(--section-gap) }
```

`--section-gap` — 300px, на ≤1023px 180px, на ≤767px 120px. Не сокращай «чтобы влезло»: воздух здесь и есть дизайн.

Исключения: hero — свой `padding-bottom: 200px`; `.dark-section` — внутренние 120px сверху и снизу.

`main` уже имеет `padding-top: calc(var(--header-top) + var(--header-h))`, повторять в секциях не нужно.

Шкала gap: `--gap-xs` 6, `--gap-sm` 8, `--gap-md` 12, `--gap-lg` 24, `--gap-xl` 36, `--gap-2xl` 40, `--gap-3xl` 60. Других значений не вводим.

Сетки: `1fr 1fr 1fr`, `1fr 1fr`, `1fr minmax(200px, 280px)`.

## Готовые классы в `base.css`

Прежде чем писать стиль в компоненте — проверь, нет ли готового:

`.container` · `.card` · `.card-title` · `.pill` · `.chip` · `.work-grid` · `.problem-solution` · `.step-list` · `.step` · `.field` · `.dark-section`

`.chip` — неинтерактивный близнец secondary-кнопки (`<li>`, не ссылка): те же шрифт, паддинги `--chip-py`/`--chip-px`, радиус `--r-btn`, зазор `--gap-icon`, ховер — `border-color: var(--ink)`. На ≤767px 15/20 и паддинги меньше.

`.card-title` — заголовок внутри карточки: 28px/1.2, трекинг −0.56px, вес 600, `max-width: var(--measure-card-head)`, `margin-bottom: 0` — ритм внутри карточки задаёт сама карточка. На ≤1279px 24px (узкие карточки мозаики), на ≤1023px 26px, на ≤767px 22px/1.3 и −0.3px.

## Компоненты

**Кнопка** — `src/components/ui/BaseButton.vue`. Варианты `primary` / `secondary` / `ghost`, размеры `md` / `lg`. Пропсы `arrow` (стрелка-рикошет) и `roll` (прокрутка букв). Третьего типа кнопок нет. Оранжевых кнопок нет.

**Бегущая строка стека** — `src/components/ui/StackMarquee.vue`, проп `items` — массив id из `src/data/stack.json` (`{ id, name, icon? }`, `icon` — имя SVG в `src/assets/stack/`, без него пилюля только с текстом). Стек главной — `src/data/stack-home.json`, стек услуги — поле `stack` в `services.json`. Список рендерится дважды, CSS-анимация `translateX(0 → -50%)` за `--marquee-duration`; короткий стек повторяется внутри половины до 14 пилюль, повторы `aria-hidden`. Пауза при наведении, края гаснут маской (`--marquee-fade`) — это обрезка, не декоративный градиент. При `prefers-reduced-motion` анимации и маски нет, пилюли переносятся. Иконки встраиваются инлайном через `?raw` и попадают в пререндер. В SVG не должно быть `id` и градиентов.

Общие токены кнопки и чипа: `--r-btn`, `--btn-py`, `--btn-px`, `--gap-icon`. Карточка услуги: `--r-xl` (20), `--card-mark-w` (112, линия-маркер), `--mosaic-row` (120, ряд мозаики), `--arrow-card` (28, на ≤767px 20 через `--arrow-card-mobile`), `--service-card-h-mobile` (200, min-height на ≤767px). Стек: `--stack-icon` (18, на ≤767px 16), `--marquee-duration`, `--marquee-fade`.

**Прокрутка букв** — `src/components/ui/RollingText.vue`, задержка 25 мс на букву. Используется на пунктах меню. На кнопках — только `arrow`, без `roll`: один элемент, один приём.

**Стрелка-рикошет** — `src/components/ui/RicochetArrow.vue`, проп `size` (по умолчанию 16px, в карточках услуг `var(--arrow-card)`). Сама наведение не слушает: владелец ставит на себе `--ricochet-p: 1` (hover, `:active`, `:focus-visible`), цвет — `currentColor`, второй стрелке можно задать `--ricochet-second`. Механика: контейнер 16×16 с `overflow: hidden`, две одинаковые SVG, вторая на `left: -16px; top: 16px`. При наведении обе на `translate(16px, -16px)`, `transition: .38s cubic-bezier(.22,1,.36,1)`. Диагональ совпадает с направлением стрелки.

## Вложенные скругления

Внешний радиус = внутренний + отступ между ними. Кнопка `r=15` внутри панели с отступом 12 → панель `r=27`. Одинаковый радиус снаружи и внутри читается как ошибка.

## Анимации

GSAP, инициализация в `onMounted`, **обязательная очистка в `onUnmounted`** — иначе при переходах между страницами таймлайны накапливаются.

Базовый набор: появление секций `opacity 0→1`, `y: 24→0`, `duration .6`, `ease power2.out`, `stagger .08`. Ховеры — обычным CSS `transition: var(--ease)`, не GSAP.

**Запрещено:**

- Перехват скролла и кастомный smooth-scroll
- Pinned-секции, удерживающие экран дольше одной высоты вьюпорта
- Общая высота страницы больше 8000px

Наложения в таймлайне писать строго `"-=0.8"`. Форма `"=-.8"` синтаксически неверна: GSAP считает такую строку меткой, несуществующая метка ставится в конец, наложение молча не срабатывает.

`prefers-reduced-motion: reduce` отключает всё — уже прописано глобально в `base.css`.

## Доступность

- Текст, разбитый на буквы или появляющийся только при наведении, помечается `aria-hidden`, а подпись дублируется в `aria-label`. Иначе скринридер прочитает слово по буквам, а поисковик не увидит его вовсе
- `:focus-visible` — `outline: 2px solid var(--ink)` с `outline-offset: 2px`
- Ховер не существует на тач-устройствах. В `@media (hover: none)` подписи показываются всегда
- Изображения: `width`, `height`, `loading="lazy"` кроме hero, осмысленный `alt`

## Сборка и деплой

`vite-ssg build` → `dist`. Каждый маршрут должен стать отдельным HTML-файлом с текстом в исходном коде, а не подгружаемым скриптом. Чистый SPA без пререндера не сдавать.

GitHub → Timeweb Cloud App Platform, тип «фронтенд», команда `npm run build`, директория `dist`.

## Текущее состояние

На главной (`HomeView.vue`) сейчас подключены только `HeroSection` и `ServicesIntro`. Работаем по одному модулю за раз, сверху вниз.

**`WorksSection.vue` и `WorksGrid.vue` отключены намеренно** — блок работ будет переделан полностью. Не подключай их обратно и не правь, пока не поступит отдельная задача.

Компоненты, где типографика переопределена локально и расходится с системой:

- `HeroSection.vue` — `font-weight: 700`, `font-size: 58px` вместо 52/500. **Оставлено намеренно по просьбе владельца, не трогать**

`ServicesIntro.vue` приведён к системе. Слева липкая вводная без кнопки: `.pill`, `<h2 class="h1">` (визуально h1, семантически h2), параграф. Справа мозаика из шести карточек-ссылок из `services.json` (поле `description`): сетка `1fr 1fr`, `grid-auto-rows: var(--mosaic-row)`, высокие карточки на 3 ряда, низкие на 2, крест-накрест (1, 4, 5 — высокие), позиции через `:nth-child`, порядок в DOM 1…6. В низких карточках (2, 3, 6) описания короткие. На ≤1023px вводная уходит наверх, мозаика остаётся; на ≤767px одна колонка, 1…6. Внизу секции — бегущая строка стека (отдельным `.container` после сетки, иначе липкая вводная наедет на неё).

При работе над новым модулем сверяйся с этим файлом до того, как писать стили.
