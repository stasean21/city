# Что заполнить на сайте m/design

Отвечайте по номерам. Файлы — в Yandex Object Storage, бакет landing-main, по путям ниже.

## А. Общее и контакты
1. Имя для сайта (как подписывать в «Обо мне» и в чатах)
2. Реквизиты в футере: ФИО для «ИП …» и ИНН — или убрать строку
3. Telegram — ник
4. WhatsApp — номер
5. Vk — адрес страницы
6. Max — ссылка на профиль
7. Email
8. Домен сайта
9. Отзывы: цифры «30+ отзывов» и «130+ повторных заказов» — это правда? Если нет — какие

## Б. Цены и сроки (для каждого пакета: «от … ₽» и «срок от … дней»)
10. Инфографика: Главный слайд / Карточка целиком / Серия товаров + сколько слайдов в полной карточке
11. Предметная съёмка: Несколько кадров (до … кадров) / Набор для карточки (до … кадров на товар) / Каталог (от … товаров)
12. Видеообложки: Одна обложка / Набор для теста (… вариантов зацепки) / Серия (от … роликов)
13. Баннеры: Один креатив (до … размеров) / Набор под площадки (до … размеров) / Кампания с тестами (… вариантов)
14. Сайты: Лендинг / Сайт услуг / Поддержка (что входит и срок или формат «в месяц»)
15. ИИ-агенты: Бот для заявок / Агент с базой ответов / Агент + отчёты (какие CRM подключаете)

## В. Ответы по услугам
16. Инфографика: отдаёте исходники? В каком формате? Может ли клиент сам менять карточку?
17. Съёмка: какие фото товара нужны от клиента и сколько?
18. Видео: на каких площадках показывается видеообложка; требования площадок (длительность, формат, вес)
19. Видео: ваши ролики какого формата — 3:4 (как обложка WB) или 9:16?
20. Сайты: на чём делаете (свой код / Tilda / оба — когда что)
21. Сайты: как передаёте сайт и может ли клиент править сам
22. Агенты: где работают кроме Telegram и сайта (VK, WhatsApp, Max)
23. Агенты: где хранятся данные клиентов
24. Агенты: кто платит за ИИ-сервисы и автоматизацию (аккаунт клиента или ваш)

## Г. Файлы
Формат: фото и картинки — WebP (качество 80–85). Если неудобно — JPG/PNG, конвертируем скриптом. Видео — MP4 (H.264), без звука. Имена — латиницей, без пробелов.
25. Обо мне — about/: design.webp, ads.webp, data.webp (4:5, 1200×1500), avatar.webp (1:1, 400×400)
26. Инфографика — works/<slug>/: cover.webp + 01.webp…NN.webp (3:4, 900×1200), 8–12 работ
27. Съёмка — works/<slug>/: cover.webp, форма — 4:5 (1080×1350), 5:4 (1350×1080) или 1:1 (1080×1080), от 9 работ
28. Видео — works/<slug>/: cover.mp4 (до 10 с, до ~5 МБ) + poster.webp (первый кадр, тот же размер), 6–8 роликов
29. Баннеры — banners/<кампания>/: <ширина>x<высота>.webp для каждого размера, 3–4 кампании. Сейчас на сайте размеры 1080×1080, 1080×1440, 1440×1080, 1440×810, 1440×405 — если ваши другие, пришлите список
30. Отзывы — reviews/: скрины 01.webp…12.webp (ширина 600–800) + для каждого: имя, ниша, услуга (с согласия клиента). Аватары по желанию — 1:1, 160×160
31. Логотип Max — SVG (официальный)
32. Картинка для соцсетей при отправке ссылки — 1200×630 (по желанию)
33. Скриншоты сайта для страницы «Сайты» — НЕ нужны, их делает скрипт npm run shoot:home

## Д. Данные по работам
34. Для каждой работы: название товара, ниша, услуга, порядок показа (лучшие — первыми)
