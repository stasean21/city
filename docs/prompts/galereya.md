## 1. Что поменять относительно исходного React-компонента
- Vue 3 + <script setup>, GSAP. Никаких window._closeLb и прочих глобальных функций — обычные функции компонента.
- Фон var(--bg) (беж), не чёрный. Карточки — радиус var(--r-card), фон var(--white), БЕЗ теней, свечений, backdrop-filter.
- Убрать: координаты, мини-карту, подсказку капсом с letter-spacing. Вместо них снизу по центру пилюля «● тяните в любую сторону» (белая, .small, var(--ink), точка var(--accent)), исчезает после первого перетаскивания или колёсика.
- Номер-бейдж на карточке → пилюля снизу слева: название работы + ниша (ниша var(--text-3)).
- Сверху слева — белая пилюля «{название услуги} · {N} работ»; справа — круглая кнопка закрытия 48px var(--ink) с иконкой ×, ховер var(--ink-hover).
- Количество работ — любое (не жёстко 24): сетка COLS = ceil(sqrt(N*1.5)), ROWS = ceil(N/COLS), повтор сетки 5×5 (REPEAT 2) для бесконечности; если N не делится — индексы по модулю N.
- Размер плитки: 240×320 (3:4), gap 24; на ≤767 — 180×240, gap 16. Токены: --gallery-tile-w: 15rem, --gallery-gap: var(--s-24); мобилка 11.25rem / var(--s-16).
- Картинки: cover работы, object-fit cover, loading="lazy", decoding="async", alt «{название}, {ниша}». Для баннеров (разные пропорции) — object-fit: contain на белом фоне плитки.

## 2. Поведение (как в макете)
- Перетаскивание pointer-событиями (мышь и тач одним кодом), touch-action: none на галерее. При начале перетаскивания (сдвиг > 5px) — плавный отъезд scale .86 (0.45s power3.out), при отпускании — назад к 1. Клик после перетаскивания НЕ открывает работу.
- Колёсико/тачпад двигает полотно (preventDefault, passive: false).
- Стрелки клавиатуры — плавно двигают полотно через gsap.ticker (пока галерея открыта и просмотр закрыт).
- Появление: галерея fade 0.35s, центральные карточки — stagger from center (как в исходнике).
- Пока галерея открыта — у страницы overflow hidden (без прыжка ширины: компенсируй ширину скроллбара padding-right).

## 3. Просмотр одной работы (лайтбокс внутри галереи)
- Затемнение rgba на основе --ink (токен --gallery-backdrop: rgb(29 30 34 / .92)), без blur.
- По центру — картинка (радиус var(--r-card), ширина min(30rem, 78vw, (100vh − 220px) · 3/4)), под ней подпись: название (Gilroy 600 --t-h3, white) + ниша (.small, var(--dark-section-text)).
- Если у работы есть slides — показывать слайды работы (листать стрелками внутри работы); если нет — листать между работами. Счётчик снизу по центру «17 / 24» (tabular-nums).
- Стрелки ← → — круги 56px var(--ink-soft), на мобилке 44px; закрытие — круг var(--ink-soft) справа сверху; слева сверху «esc — закрыть» (.small, var(--dark-section-text), без капса; на мобилке скрыть).
- Переход между работами — сдвиг ±60px + fade (0.16s/0.24s), как в исходнике.
- Закрытие: Esc, клик по затемнению, кнопка ×. Esc при закрытом просмотре закрывает всю галерею.
- ВАЖНО: закрытый просмотр рендерить через v-if (или visibility: hidden + pointer-events: none на весь блок, включая детей). Его кнопка × стоит ровно над главной кнопкой ×: если невидимый просмотр остаётся кликабельным, он перехватывает клики и главный крестик «заедает». Никаких pointer-events: auto на кнопках внутри скрытого слоя.
- Повторный клик по × во время анимации закрытия игнорировать (флаг closing), чтобы закрытие не запускалось дважды.

## 4. Доступность
- Галерея — role="dialog" aria-modal="true" aria-label «Все работы: {услуга}». Фокус при открытии — на кнопку закрытия, при закрытии — обратно на кнопку «Смотреть все работы».
- Ловушка фокуса (Tab ходит только по кнопке закрытия и карточкам центральной копии сетки; в просмотре — по его кнопкам).
- Карточки — <button>; tabindex="0" и aria-label только у центральной копии сетки, у повторов tabindex="-1" и aria-hidden="true".
- Счётчик просмотра — aria-live="polite".
- prefers-reduced-motion: без масштабирования при драге, без stagger, без анимаций просмотра — мгновенные смены.
- :focus-visible — на светлом var(--ink), на тёмных кнопках var(--accent).
