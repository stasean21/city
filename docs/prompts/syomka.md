## 4. PhotoRows — «Работы»
Шапка как у остальных блоков (pill «Примеры», Display, lead) — внутри .container. Сами ряды — НА ВСЮ ШИРИНУ экрана (вне контейнера), overflow hidden.
Два ряда кадров, gap var(--s-16) между рядами и между кадрами. Высота кадра — токен --photo-row-h: 22.5rem (360), на ≤767 — 15rem (240). Ширина — по форме: portrait 4/5, landscape 5/4, square 1/1. Радиус var(--r-card). Картинка object-fit cover, loading="lazy", alt из caption.
Подпись на кадре: снизу слева пилюля (фон белый 88%, .caption, var(--ink)) — caption.
Работы распределяются по двум рядам поочерёдно; если работ мало — ряд дополняется повтором (повторы aria-hidden).
Движение: при прокрутке страницы ряды сдвигаются по горизонтали в разные стороны — верхний влево, нижний вправо — пропорционально прогрессу прохождения блока через экран (GSAP ScrollTrigger, scrub, БЕЗ pin, как в ReviewsWall). Амплитуда — до 60% лишней ширины ряда. Очистка в onUnmounted.
reduced motion — без движения, ряды — обычная горизонтальная прокрутка (overflow-x auto, scroll-snap).
≤767 — движение тоже есть (это главный эффект блока), если тормозит — отключи и сделай горизонтальную прокрутку пальцем.
Под рядами, внутри контейнера, по центру — кнопка BaseButton primary с arrow «Смотреть все работы», отступ сверху var(--s-40). Куда ведёт — решим позже: пока <button type="button"> без действия с TODO.
