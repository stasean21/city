## 3. Анимация (GSAP, очистка в onUnmounted)
1. Сразу при открытии, параллельно:
   - «загрузка» 1.5 с: слово после «m/» меняется каждые 150 мс по списку design, cards, photo, motion, web, agents, data, ... (как в TheLoader); полоса и процент растут с ease-out до 99% и застревают; затем слово → «404», полоса → accent.
   - барабан: в каждой колонке лента из случайных цифр, последняя — нужная (4, 0, 4). Длина ленты 18 / 26 / 34 цифры, длительность 1.4 / 1.85 / 2.3 с, ease power4.out (или expo.out) — колонки встают по очереди слева направо.
2. Когда встала последняя колонка: слэш через ноль, текст и кнопки, нижние ссылки; статус → «ошибка 404 · страница не найдена», точка перестаёт мигать.
3. Клик/тап по цифрам (или Enter, если в фокусе) — барабан крутится заново (новые случайные ленты), заканчивается снова на 404; слэш убирается на время прокрутки и появляется снова.
4. Автоповтор: через 12 с после каждой остановки барабан сам крутится заново (та же прокрутка, что по клику). Ручной клик сбрасывает отсчёт — следующий автоповтор через 12 с после его остановки. Во фоновой вкладке (document.hidden) не крутить — отложить до возвращения. Текст, кнопки и нижние ссылки во время повторной прокрутки НЕ скрываются — прячется только слэш (видимость текста завязана на «страница готова», а не на «барабан стоит»).
- prefers-reduced-motion: никакой прокрутки и никакого автоповтора — сразу 404 со слэшем, полоса на 99%, весь текст виден.
- Таймеры (включая 12-секундный)/raf/твины — убивать в onUnmounted (при уходе со страницы ничего не должно продолжать крутиться).

## 4. Доступность
- Барабан — role="img" aria-label="Ошибка 404"; ленты aria-hidden. Если сделать его кнопкой для повторной прокрутки — <button> с aria-label «Прокрутить цифры ещё раз», фокус по :focus-visible (outline var(--accent)).
- Статус — aria-live="polite" (объявит «страница не найдена»).
- h1 — единственный на странице.
