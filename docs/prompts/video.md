## 3. Общее для всех роликов — компонент VideoLoop.vue
- <video muted loop playsinline preload="none" :poster> — звук не нужен никогда, controls нет.
- Играет только в зоне видимости: IntersectionObserver (threshold .3) → play() / pause(); при уходе вкладки — pause. preload="none" и src подставлять при первом появлении — чтобы страница не грузила все MP4 сразу.
- prefers-reduced-motion: не запускать, показывать poster.
- object-fit cover, aria-hidden (декоративное видео); смысл — в подписи рядом.
- Пока видео не загрузилось — фон var(--bg-3) (как CoverImage для 404 картинок).

## 5. VideoFeed — «Заметна в выдаче» (вариант A)
Сетка: слева телефон (колонка minmax(17.5rem, 23.75rem)), справа текст; gap var(--s-60); align center.
- Телефон: корпус var(--ink), радиус --phone-r: 2.5rem, внутренний отступ var(--s-12); экран белый, радиус 1.875rem, высота --phone-screen-h: 38.75rem (620), на ≤767 — 32.5rem.
- Вверху экрана — строка поиска (фон var(--bg-3), радиус var(--r-lg), .small var(--ink)) с page.feed.query.
- Под ней лента маркетплейса: 2 колонки, gap var(--s-8)…var(--s-12), 16 карточек. Карточка: картинка 3:4 радиус var(--r-lg), цена (.small, 600, var(--ink)) — «[—] ₽», две серые строки-заглушки названия.
  Обычные карточки — статичные постеры (poster других работ / нейтральные заглушки), 2 карточки — ваши видеообложки (VideoLoop первой работы) с обводкой 2px var(--accent) и пилюлей «видео» (var(--ink), белый, .caption) в углу.
- Лента сама медленно прокручивается вверх-вниз (requestAnimationFrame, ~20px/с, туда-обратно); колесо мыши / свайп внутри телефона — ручная прокрутка, автопрокрутка возобновляется через 2.5 с после последнего действия. Прокрутка страницы колесом над телефоном не блокируется намертво: если лента в крайнем положении — отдай событие странице.
  Без reduced motion: авто; с reduced motion — без автопрокрутки.
- Справа: Card title «Покупатель листает выдачу за секунды», абзац «Видеообложка двигается прямо в результатах поиска — глаз цепляется за неё раньше, чем за соседние карточки. Покрутите ленту в телефоне: ваша карточка обведена.», легенда: «обычная карточка» (квадратик var(--bg-3)) и «с видеообложкой» (квадратик с обводкой var(--accent)).
- Телефон декоративный: aria-hidden; смысл передаёт текст справа.
≤767: одна колонка, телефон сверху по центру (max-width 20rem).

## 6. VideoReel — «Работы» (вариант B)
Шапка без pill: Display page.works.title + lead.
Сетка 4 колонки, gap var(--s-16); каждая вторая колонка сдвинута вниз на var(--s-48) (шахматка), под сеткой компенсирующий отступ.
Ролик: 9:16, радиус var(--r-card), VideoLoop. Снизу поверх: слева пилюля с названием (белая, .caption, var(--ink)), справа пилюля длительности «0:07» (var(--ink), white, tabular-nums).
Клик по ролику — открыть его крупно: если WorksGallery уже есть в проекте — галерея с роликами этой услуги (в просмотре — <video> с controls, muted по умолчанию); если нет — SlidesLightbox с одним видео. Обязательно Esc и возврат фокуса.
Под сеткой по центру — кнопка «Смотреть все работы» (как на других страницах: если WorksGallery подключена — открывает её, иначе <button> с TODO).
≤767: 2 колонки, сдвиг var(--s-32).
