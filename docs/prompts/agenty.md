## 4. AgentDemo — демо-чат (вариант A)
- Над блоком: пилюля-пометка demo.note (белая, .caption, точка var(--accent)) и переключатель сценариев — пилюли (активная var(--ink)/white, aria-pressed).
- Сетка minmax(18.75rem, 1fr) 1.15fr, gap var(--s-16), одинаковая высота --agent-demo-h: 35rem (на ≤767 — 30rem, колонки друг под другом).
- Слева чат: белая карточка радиус var(--r-stage); шапка — аватар «m/» (круг 40px var(--ink), слэш var(--accent), не переносится), «Помощник m/design», подпись «отвечает клиенту»/«пишет вам», справа пилюля канала. Лента сообщений с внутренней прокруткой, без видимого скроллбара; клиент — справа var(--bg-3), агент — слева var(--bg); перед ответом агента — «печатает…» (три точки) ~0.9 с.
- Справа «За кулисами»: карточка var(--ink), заголовок + «сейчас»; лента событий (до 4 последних, точка var(--accent), ключевые слова white); мини-таблица заявок (фон var(--ink-soft), 4 колонки: Клиент, Задача, Площадка, Статус; новая строка появляется сверху с кратким подсвечиванием, статус — пилюля var(--accent) на прозрачном); внизу всплывает уведомление (белая плашка с иконкой Telegram-цвета и текстом), opacity+translateY.
- Логика: сценарий играет пошагово (тайминги из макета). Запуск — когда блок впервые попал в зону видимости; после окончания пауза 5 с и следующий сценарий по кругу. Клик по пилюле — сразу этот сценарий (предыдущий прерывается через токен запуска). Кнопка «↻ проиграть заново» под блоком. Вне экрана/во фоновой вкладке — пауза.
- reduced motion: без «печатает» и задержек — сценарий выводится сразу целиком.
- Доступность: лента чата и «за кулисами» — aria-live="polite"; переключатель — role="group".
- Очистка таймеров и observer в onUnmounted.

## 5. AgentThink — «как агент думает» (вариант F)
- Тёмная карточка var(--ink), радиус var(--r-stage), padding var(--s-32) (≤767 — var(--s-20)).
- Сверху три «входящих сообщения» — кнопки-пузыри (var(--ink-soft)/white, активное — white/var(--ink)), aria-pressed.
- Ниже 4 шага в ряд (≤767 — 2×2): карточки var(--ink-soft), номер var(--accent), заголовок Gilroy 600 white, текст .small var(--dark-section-text), внизу пилюля-итог. Шаги 1–3 из кейса, шаг 4 — финал: ok → белая карточка (текст var(--ink)/var(--text), пилюля var(--accent)); hand → белая карточка с обводкой 2px var(--accent) (НЕ сплошная оранжевая заливка — акцент ~1%), пилюля var(--ink).
- При выборе сообщения шаги загораются по очереди (opacity .35→1, y 6→0, шаг ~0.65 с). Первый кейс запускается при появлении блока на экране. reduced motion — сразу все шаги.
- Подвал карточки: think.footnote слева и справа.
- Доступность: ряд шагов — aria-live="polite".
