# «Рекламные баннеры» и «Лендинги и сайты» — страницы показывают 404

Прочитай `CLAUDE.md`. Две услуги пока не готовы: `reklamnye-bannery` и `lendingi-i-sayty`. Пока мы их дорабатываем, **их страницы показывают 404**: «Этой страницы нет. Или она ещё в работе».

**Всё остальное остаётся как есть:**
- карточки на главной (все 6);
- ссылки в «С этим часто берут»;
- данные и компоненты этих страниц.

Человек нажимает на карточку и попадает на 404 «в работе». Так и задумано.

## 1. Флаг в данных — `src/data/services.json`

Обеим услугам добавить поле `"draft": true` (рядом со `slug`). Больше в их данных ничего не менять.

## 2. Маршрут — `src/router/index.js`

В `serviceExists` услуга с `draft: true` обрабатывается так же, как несуществующая: возврат на `not-found`, адрес в строке не меняется.

```js
function serviceExists(to) {
  const service = services.find((s) => s.slug === to.params.slug)
  // draft — страница ещё в работе: показываем 404 «Этой страницы нет. Или она ещё в работе»
  if (service && !service.draft) return true
  return { name: 'not-found', params: { pathMatch: to.path.slice(1).split('/') }, query: to.query, hash: to.hash }
}
```

## 3. Пререндер — `vite.config.js`

Пререндерить `/services/<slug>` только для услуг без `draft`. Для черновиков HTML в `dist` не создаётся, и хостинг сам отдаёт `404.html`.

## 4. Ничего не скрывать

`ServicesIntro.vue`, `RelatedServices.vue`, `TheLoader.vue`, `ServiceDetailView.vue` **не трогать**. Карточки и ссылки на эти две услуги остаются.
