# Скрыть «Рекламные баннеры» и «Лендинги и сайты» до доработки

Прочитай `CLAUDE.md`. Две услуги пока не готовы: `reklamnye-bannery` и `lendingi-i-sayty`. Пока их доделываем:
- их страницы отдают 404 («Этой страницы нет. Или она ещё в работе» — подходит дословно);
- на сайте на них нет ни одной ссылки.

Данные и компоненты этих страниц **не удаляем**: потом включим обратно одной строкой.

## 1. Флаг в данных — `src/data/services.json`

Обеим услугам добавить поле `"draft": true` (рядом со `slug`). Больше в их данных ничего не менять.

## 2. Общий список опубликованных услуг

Создать `src/data/published.js`:

```js
import services from './services.json'

// услуги с draft: true не показываются нигде и отдают 404 — страница ещё в работе.
// включить обратно: убрать draft в services.json
export const publishedServices = services.filter((service) => !service.draft)
```

Везде, где сейчас импортируется `services.json` для показа или ссылок, брать `publishedServices`:
- `src/components/sections/ServicesIntro.vue` — карточки на главной;
- `src/components/service/RelatedServices.vue` — «С этим часто берут»: скрытые слаги просто пропускаются. Если в блоке не осталось ни одной услуги, блок не выводится;
- `src/router/index.js` — `serviceExists`: черновик → 404, как несуществующий адрес;
- `vite.config.js` — пререндер `/services/<slug>` только для опубликованных (черновики не попадают в `dist`);
- `src/views/ServiceDetailView.vue` — поиск услуги по слагу только среди опубликованных.

`TheLoader.vue` можно оставить на полном `services.json`: на скрытую страницу он всё равно не попадёт. Проверь grep'ом `services.json` по `src`, чтобы не пропустить другие места. Если найдёшь ещё — скажи мне.

## 3. Сетка на главной — 4 карточки вместо 6

`ServicesIntro.vue` сейчас рассчитан на 6 карточек зигзагом. Для 4 карточек:
- **ПК, 3 колонки:** ряд 1 — карточка 1 широкая + 2; ряд 2 — 3 + карточка 4 широкая. Зигзаг сохраняется. Правило для `nth-child(5)` больше не срабатывает — его не удалять (вернётся с баннерами), но проверь, что сетка ровная;
- **≤991, 2 колонки:** 1 широкая, 2 + 3, 4 широкая. Без одиночной полуширинной карточки в последнем ряду;
- **≤767:** столбик.

Лучше сделать правила, которые работают и для 4, и для 6 карточек (например, `li:last-child:nth-child(4)`), чтобы при возврате услуг ничего не переписывать. Обнови комментарий над сеткой.
