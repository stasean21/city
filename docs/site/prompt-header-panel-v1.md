# Шапка: вся шапка — одна белая панель, радиусы по правилу вложенности

Прочитай `CLAUDE.md` (раздел «Вложенные скругления»). Файлы: `src/components/layout/TheHeader.vue`, `src/styles/tokens.css`. Этот промпт **заменяет** визуальную часть `prompt-nav-segment-v1.md`. Скользящую плашку и её расчёт (`placePill`, `watch(activeHash)`, `resize`, `document.fonts.ready`) оставить и только перекрасить.

Макет — вариант **B** в `docs/site/header-mockup/7-nav-panel-a-b.png` и `nav-panel-mockup.html` (класс `.b`) в ветке `claude/site-overview-setup-iskpz2`.

Меняется только десктоп (> 767px). Мобильную шапку (логотип сверху + нижняя панель), подсветку текущего блока, закрепление на 10 секунд и прятание при прокрутке вниз не трогать.

## 1. Токены

```css
/* шапка-панель: кнопка r-btn (15) внутри панели с отступом s-8 → радиус панели 15 + 8 = 23 */
--header-pad: var(--s-8);
--header-r:   calc(var(--r-btn) + var(--header-pad));
```

## 2. Панель — `.site-header__inner`

- Всегда белая (`background: var(--white)`), в том числе на первом экране, не только после прокрутки.
- `border-radius: var(--header-r)` вместо `calc(var(--header-h) / 2)`.
- Внутренние отступы: `var(--header-pad)` сверху, справа и снизу, слева `var(--s-24)` (воздух перед логотипом).
- Высота панели = высота кнопки + 2 × `--header-pad`. Если `--header-h` (70) не совпадает с этим, поставь `--header-h` равным фактической высоте панели (кнопка 44 → 60, `3.75rem`). Тогда отступ `main` и `scrollBehavior` останутся верными: они читают токен.
- Класс `has-bg` больше не меняет фон, панель белая всегда. Если от него ничего не осталось, удали класс и его логику, но `isScrolled` не трогай, если он нужен для чего-то ещё.
- Теней нет.

## 3. Меню — `.site-header__nav`

- Убрать белую капсулу меню (фон, `--r-pill`, padding): меню теперь внутри белой панели.
- `display: flex; gap: 0; position: relative;` меню стоит справа, рядом с кнопкой. Логотип прижат влево (`margin-right: auto`).
- Пункты: **высота как у кнопки** — те же вертикальные паддинги и `line-height`, что у `.btn` в `BaseButton.vue`. По горизонтали `var(--nav-link-px)`. Радиус `var(--r-btn)` (15). Цвет `var(--text)`, фона нет.
  - Ховер: только цвет `var(--ink)`, `transition: color var(--ease)`. `RollingText` остаётся.
  - Активный: цвет `var(--ink)`, `z-index: 1` над плашкой.
- От меню до кнопки — `var(--s-16)`.

## 4. Скользящая плашка — `.site-header__pill`

- Перекрасить: `background: var(--bg)` (бежевый цвет страницы) вместо `var(--ink)`.
- `border-radius: var(--r-btn)` (15), как у кнопки.
- Высота = высоте пункта: `top: 0; bottom: 0` внутри меню, если меню по высоте равно пунктам.
- Логика без изменений: ширина и положение по активной ссылке, `opacity: 0`, когда активного блока нет, без «прилёта» при появлении.

## 5. Кнопка «Обсудить задачу»

Без изменений: `BaseButton variant="primary" arrow`, радиус уже `var(--r-btn)`. Проверь, что высота кнопки и пунктов совпадает до пикселя.

## 6. Проверка

- 1440 / 1280 / 1024: белая панель с радиусом 23, внутри логотип, пять пунктов и кнопка в одну строку. Отступ от кнопки до края панели 8px сверху, справа и снизу одинаковый.
- Листаем главную: бежевая плашка с радиусом 15 плавно переезжает между пунктами. На первом экране и в контактах её нет.
- Наведение: темнеет только текст.
- Высота пунктов и кнопки одинаковая, плашка ровно по высоте кнопки.
- Прятание при прокрутке вниз и закрепление на 10 секунд после клика работают, при перемещении панель не теряет фон.
- Заголовки блоков после перехода по пункту не прячутся под шапкой (если менял `--header-h`).
- ≤ 767px — как было (логотип сверху, нижняя панель).
- `npm run build` без ошибок. Коммит: «Шапка: одна белая панель, радиусы 15/23, бежевая плашка».
