### 1.2. `items` — заменить целиком

Новые поля: `text`, `name`, `initial` (пусто — значит имени нет, показываем значок человека), `source`, `date`, `service` (пусто — без метки). Поля `image`, `width`, `height`, `alt`, `niche` больше не нужны.

**Тексты — дословно, с опечатками, пробелами и смайликами как есть.** Не исправлять: это подлинные отзывы. Неразрывные пробелы `npm run typo` может поставить, больше ничего не трогать.

## 2. Карточка — `ReviewsWall.vue`

Вместо `<img>` / `.reviews__placeholder` / `.reviews__caption` внутри `li.reviews__card`:

```
[метка услуги]          ← .pill, только если service не пустой
Текст отзыва            ← <p>, обычный body (15/25, --text), без своих размеров
(●) Имя                 ← кружок с буквой или значком; имя — класс .ui
    Авито · 3 февраля 2026   ← класс .caption, white-space: nowrap
```

- Карточка: фон `--white`, радиус `--r-card` (как сейчас), внутренний отступ `--s-24` вместо `--s-12`. Вертикально: flex-колонка, gap `--s-16`, у нижней строки дополнительно `margin-top: var(--s-8)`.
- Метка: готовый `.pill`, `align-self: flex-start`. Свою типографику не задавать.
- Кружок: 40px — добавить токен `--reviews-avatar: 2.5rem;` рядом с `--avatar` в `tokens.css`. Фон `--bg-3`, буква — шрифт заголовков (`--f-head`), цвет `--ink`, размер через существующий класс (`.h3`, как в стопке аватаров). Если `initial` пустой — внутри inline-SVG значок человека 18×18, `stroke: currentColor`, `aria-hidden="true"`.
- Кружок с буквой — `aria-hidden="true"`: имя рядом прочитается текстом.
- Нижняя строка: `display: flex; align-items: center; gap: var(--s-12)`.
- `:key` у `li` — индекс или текст, не `alt` (его больше нет).
- Подпись под карточкой (`.reviews__caption`) и `.reviews__img`, `.reviews__placeholder` — удалить вместе со стилями.
- Обработчик `load` картинок (`onImageLoad`, слушатель на `wallEl` с `capture`) больше не нужен — удалить и его, и снятие в `onBeforeUnmount`. `window` `load` → `queueRefresh` оставить: высота лент зависит от шрифтов.
- На ≤767 ширина карточки — существующий `--reviews-card-w`, `scroll-snap-align: start` — как сейчас.

Никаких звёзд, теней, оранжевого в карточках. Фото клиентов с Авито не используем.

## 3. Что не меняется

- Заголовок, подзаголовок, «Отзывы»-пилюля, легенда «30+ отзывов · 130+ повторных заказов».
- Параллакс, маска сверху/снизу, высота окна `--reviews-h`.
- JSON-LD с отзывами **не добавлять**: разметка отзывов о себе на своём сайте поисковиками не учитывается.
