# Галерея работ: перетаскивание за картинку + проверка количества работ

Прочитай `CLAUDE.md`. Файлы: `src/components/service/WorksGallery.vue`, `src/components/ui/CoverImage.vue`, `src/data/works.json` (только проверка).

## 1. Ошибка: полотно не тянется, если взяться за картинку

**Как воспроизвести.** `/services/infographics` → открыть галерею всех работ (полноэкранное полотно с заголовком «Инфографика для маркетплейсов · N работ»). Мышью зажать кнопку на **фотографии** и потянуть.

**Сейчас.** Полотно стоит на месте, за курсором тянется полупрозрачная копия картинки. Если зажать на промежутке между карточками, полотно тянется нормально.

**Причина.** Браузер запускает встроенное перетаскивание `<img>` (HTML5 drag and drop). Оно присылает `pointercancel`, и `onPointerUp` сбрасывает `dragging` до того, как сработает `onPointerMove`. Копия картинки — это «призрак» нативного drag.

**Исправить:**

1. `CoverImage.vue`: у `<img>` добавить `draggable="false"`. Картинки на сайте нигде не должны перетаскиваться как файлы, поэтому правка общая.
2. `WorksGallery.vue`:
   - на `.ig__wrap` добавить `@dragstart.prevent`, на случай других элементов внутри;
   - в `onPointerDown` для мыши (`event.pointerType === 'mouse'`) вызвать `event.preventDefault()`. Это убирает нативный drag и выделение текста. `click` после этого всё равно приходит, поэтому открытие работы по клику не ломается;
   - в стилях `.ig__wrap img { -webkit-user-drag: none; user-select: none; }`. Значения не числовые, токены не нужны.
3. Логику порога `DRAG_THRESHOLD` и «клик после перетаскивания работу не открывает» (`openView`) не менять.

**Проверка:**
- мышь: зажать на картинке и тянуть — полотно едет, призрака нет; отпустить — работа **не** открывается;
- мышь: короткий клик по картинке — открывается просмотр работы;
- тачпад и телефон (эмуляция touch в DevTools): тянуть пальцем за картинку — полотно едет, тап открывает работу;
- клавиатура: стрелки двигают полотно, Enter на карточке открывает работу;
- то же на стене работ страниц предметной съёмки и видеообложек, если там используется `WorksGallery`.
