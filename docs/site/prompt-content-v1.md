# Задача: заполнить контент сайта перед запуском (этап 1)

Работаем в ветке `main` (или в новой ветке от `main`). Перед началом прочитай `CLAUDE.md`: правила токенов, типографики и запреты действуют полностью. В этой задаче меняем **только данные и тексты**. Вёрстку и стили не трогаем.

**Не трогай:**
- `WorksSection.vue`, `WorksGrid.vue`, `works.json`, `banners.json`. Работы будут заменены позже отдельной задачей.
- Шапку (`TheHeader.vue`) и пункты меню. Шапка переделывается следующей задачей.
- Страницы `/works`, `/about`, `/contacts`, `/privacy`, `/works/:slug`. Их наполняем позже.
- Блок отзывов `ReviewsWall` и `reviews.json`. Скриншоты появятся позже. Цифры «30+» и «130+» верные, оставить как есть.

Главное правило: **ни одного `[—]`, `[уточнить]`, `[Имя]`, `[ФИО]` и подобных скобок в собранном сайте не должно остаться**, кроме мест, которые ниже прямо названы «оставить». Цифры, сроки и метрики, которых нет в этом документе, не придумывать.

## 5. Техническое

- `index.html`: `lang="en"` → `lang="ru"`.
- `/styleguide` — служебная страница. Исключить из пререндера (фильтр в `ssgOptions.includedRoutes` в `vite.config.js`) или добавить ей `<meta name="robots" content="noindex">` через `useHead`. Лучше исключить.
- Заголовки страниц: главная — «m/design — инфографика и ИИ-фото для маркетплейсов», плюс `meta description` (1–2 предложения по смыслу Hero). Для страниц услуг `useHead` уже есть, проверь, что title и description заполнены без скобок.
- **Не делать в этой задаче:** `sitemap.xml`, `robots.txt`, Яндекс Метрику, политику конфиденциальности. Домен и метрика будут на финальном этапе.

## 6. Проверка перед коммитом

1. `npm run build` без ошибок.
2. Поиск по `dist/`: `grep -rlE "\[(—|уточнить|Имя|ФИО|номер|ник|адрес|max)" dist` должен вернуть пусто. Исключение: страницы `/works/*`, их пока не трогаем.
3. Открыть главную и 6 страниц услуг в `npm run preview`, проверить блок цен на мобильной ширине (375px): «Цена по запросу» и «150 ₽ за секунду» не должны ломать карточку.
4. Коммит одним сообщением: «Контент: контакты, реквизиты, цены и тексты услуг».
