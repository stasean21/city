## Шаг 1. Не показывать загрузочный экран при переходе к блоку на той же странице

**Сейчас.** На главной клик по пункту меню (`/#process`, `/#reviews` и т. д.) запускает анимацию `TheLoader` (шторки и слова), как при переходе на другую страницу. Так быть не должно.

**Нужно.** Если меняется только якорь или query, а путь страницы тот же, загрузочный экран не показывается и страница плавно прокручивается к блоку. Анимация остаётся только при смене страницы (например, `/services/infographics` → `/`).

Правка в `src/components/layout/TheLoader.vue`, в обоих гвардах:

```js
removeBeforeGuard = router.beforeEach((to, from) => {
  if (from.matched.length === 0) return true
  // тот же путь, сменился только якорь или query — без шторок, просто прокрутка
  if (to.path === from.path) return true
  return leaveTransition(to)
})
removeAfterGuard = router.afterEach((to, from) => {
  if (from.matched.length === 0) return
  if (to.path === from.path) return
  enterTransition()
})
```

Проверь, что внутри `leaveTransition` и `enterTransition` нет другого места, где сравнение путей нужно повторить (например, блокировка скролла `stopScroll()`, курсор `wait`). Скролл не должен блокироваться при переходе к якорю.

**Плавная прокрутка.** `scrollBehavior` в `src/main.js` возвращает `{ el: to.hash, top: headerOffset() }`. Добавь `behavior: 'smooth'` только для перехода внутри той же страницы. При переходе с другой страницы прокрутка мгновенная: шторки закрывают экран, плавная прокрутка под ними не нужна.

```js
scrollBehavior(to, from) {
  if (to.hash) {
    const samePage = to.path === from.path
    return { el: to.hash, top: headerOffset(), behavior: samePage ? 'smooth' : 'auto' }
  }
  return { top: 0 }
},
```

При `prefers-reduced-motion: reduce` прокрутка мгновенная: проверь `window.matchMedia('(prefers-reduced-motion: reduce)').matches` и ставь `'auto'`.

**Повторный клик по тому же пункту.** Если адрес уже `/#reviews`, пользователь прокрутил страницу и снова нажал «Отзывы», vue-router не делает навигацию: адрес тот же, и `scrollBehavior` не вызывается. В шапке, в обработчике клика по пункту меню: если `route.path === '/'` и `route.hash === link.hash`, вызови прокрутку вручную тем же расчётом отступа (вынеси `headerOffset()` из `main.js` в `src/utils/headerOffset.js` и импортируй в обоих местах). Это относится и к плиткам мобильного меню, и к кнопке «Обсудить задачу» (`#contact`).

**Проверка шага:**
- главная → клик «Этапы работы» → плавная прокрутка, шторок нет;
- ещё раз «Этапы работы» после прокрутки вверх → снова прокручивает;
- `/services/infographics` → клик «Отзывы» → шторки играют, после них главная на блоке отзывов, заголовок не под шапкой;
- кнопка «Назад» в браузере после якорных переходов не запускает шторки, пока путь тот же.
