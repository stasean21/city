# Ярлык подарка останавливается над подвалом

Прочитай `CLAUDE.md`. Файл: `src/components/layout/GiftOffer.vue`.

Сейчас ярлык «Ваш подарок» закреплён справа внизу (`position: fixed`). Когда страница докручена до конца, он висит поверх подвала: перекрывает ссылки, кнопку «Наверх» и реквизиты.

Нужно: **ярлык едет вместе с экраном, но не заходит на подвал.** Когда верх подвала поднимается до ярлыка, ярлык упирается в него и дальше поднимается вместе с подвалом. Между ярлыком и подвалом всегда зазор `--s-12`. Если прокрутить обратно вверх — ярлык опускается на своё обычное место.

## Как сделать

1. В `GiftOffer.vue` к уже существующему обработчику прокрутки (`queueDark`, один `requestAnimationFrame` на кадр) добавить расчёт подъёма. Новых слушателей `scroll` не заводить.

```js
// подвал поднялся выше ярлыка — поднимаем ярлык над ним, с зазором
const footer = document.querySelector('.site-footer')
const lift = footer
  ? Math.max(0, window.innerHeight - footer.getBoundingClientRect().top - tabBottom + gap)
  : 0
```

   - `tabBottom` — текущий нижний отступ ярлыка от края окна. Его надо прочитать из CSS один раз при монтировании и на `resize`: на ПК это `--s-24`, на ≤767 — `calc(var(--dock-h) + …)` над нижней панелью;
   - `gap` — значение `--s-12` в пикселях;
   - подъём записывать в CSS-переменную на ярлыке: `tabEl.style.setProperty('--gift-lift', lift + 'px')`.

2. В стилях сдвигать ярлык **свойством `translate`**, а не `transform`: `transform` уже занят подъёмом при наведении, и они не должны перебивать друг друга.

```css
.gift-tab {
  translate: 0 calc(-1 * var(--gift-lift, 0px));
}
```

   Без `transition` на `translate`: ярлык должен идти ровно за подвалом, без запаздывания.

3. Пересчитывать подъём:
   - при прокрутке;
   - на `resize`;
   - при смене страницы (`route.fullPath`) — у страниц разная высота;
   - когда ярлык появляется (`state === 'tab'`).

   `checkDark()` вызывать **после** расчёта подъёма: ярлык может оказаться над тёмным подвалом, и тогда он должен стать светлым. Подвал уже `on-dark`. Если у него нет `data-dark-zone`, добавь атрибут в `TheFooter.vue`, чтобы ярлык над ним был светлым, а не сливался.

4. Окно подарка (модалка) не трогать: оно открывается по центру и от подвала не зависит.

5. Всё — только в браузере (`onMounted`), очистка в `onUnmounted` уже есть: проверь, что новых слушателей не добавилось.
