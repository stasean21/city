## 2. Контакты — `src/data/contacts.json`

Добавь Max **последним**: Telegram, WhatsApp, VK, Max.

```json
{ "id": "max", "name": "Max", "url": "https://max.ru/u/f9LHodD0cOIzd1DR_dyDsswoXp9vJ-f2jdaVOxF6CqBnHAWpu7NckxBqBw0" }
```

`src/utils/messengers.js` подхватывает `svg` и `mono` по `id` через `import.meta.glob`, правки в нём не нужны. Проверь, что для `max` оба поля не `null`.

## 3. Где проверить, что четыре иконки помещаются

- **Футер, компьютер:** почта-капсула и четыре круга в одну строку, на 1024 ничего не переносится.
- **Футер, телефон 360–375:** почта и четыре круга в одну строку. Если не помещаются, почта уходит на отдельную строку на всю ширину, а четыре круга встают строкой ниже. Почту не обрезать.
- **Мобильное меню (шторка):** ряд кнопок мессенджеров — четыре кнопки `flex: 1` в одну строку.
- **Блок контактов на главной (`ContactCta`):** четыре пункта, вёрстка не ломается.
- У всех ссылок `target="_blank" rel="noopener"`, `aria-label="Написать в Max"`.

## 4. Готово, когда

`npm run build` без ошибок; в `dist/index.html` есть ссылка на Max; коммит «Контакты: Max».
