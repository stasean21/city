# Задача: новая шапка — навигация по блокам главной (компьютер) и нижняя панель (телефон)

Работаем от актуального `main`. Перед началом прочитай `CLAUDE.md` и следуй ему: токены вместо чисел, никаких теней, градиентов и стекла, `<RouterLink>` для внутренних ссылок, GSAP не нужен — только CSS-переходы `var(--ease)`, `prefers-reduced-motion` уже отключает анимации глобально.

Макеты лежат в ветке `claude/site-overview-setup-iskpz2`, папка `docs/site/header-mockup/`:
- `1-desktop-a-b-c.png` — берём **вариант C** (нижний);
- `5-mobile-varianty-1-2-3.png` — берём **вариант 3** (правый столбец);
- `mobile-menu-mockup.html` — статичный HTML мобильного варианта 3. Размеры и цвета смотри там (класс `.v3`), но переноси через токены.

Файлы: `src/components/layout/TheHeader.vue`, `src/styles/tokens.css`, новый composable `src/composables/useActiveSection.js`. Другие компоненты не трогай, кроме нижнего отступа футера на телефоне (п. 4).

## 1. Пункты меню

```js
const navLinks = [
  { label: 'Услуги',       hash: '#services' },
  { label: 'Этапы работы', hash: '#process' },
  { label: 'Отзывы',       hash: '#reviews' },
  { label: 'Обо мне',      hash: '#about' },
  { label: 'FAQ',          hash: '#faq' },
]
```

- Ссылки: `<RouterLink :to="{ path: '/', hash: link.hash }">`. С любой страницы ведут на главную к нужному блоку. Прокрутку с отступом под шапку уже делает `scrollBehavior` в `src/main.js`, его не трогать.
- Отключи встроенную подсветку RouterLink: `active-class=""` и `exact-active-class=""`. Иначе на главной все пять пунктов подсвечиваются разом, потому что путь у всех `/`.
- Кнопка «Обсудить задачу» в шапке и в мобильной панели ведёт на `{ path: '/', hash: '#contact' }` (блок `ContactCta`), а не на `/contacts`.
- id секций уже есть: `#services`, `#process`, `#reviews`, `#about`, `#faq`, `#contact`. Проверь, что ни один не переименован.

## 2. Подсветка текущего блока — `useActiveSection.js`

- `IntersectionObserver` на пять секций по id. Активной считается секция, которая пересекает горизонтальную линию примерно на трети высоты экрана: `rootMargin: '-33% 0px -66% 0px'`.
- Возвращает `ref` с hash активной секции или `''`. Пустая строка — когда пользователь в hero, в `#contact`, в футере или не на главной (`route.name !== 'home'`).
- Подписка в `onMounted`, `observer.disconnect()` в `onUnmounted`. Переход между страницами не должен оставлять наблюдателей.
- На сервере (SSG) код не выполнять: всё внутри `onMounted`.

Активный пункт получает класс `is-active` и `aria-current="true"`.

## 3. Компьютер и планшет (> 767px) — вариант C

Структура остаётся прежней: логотип слева, пункты, кнопка справа, плавающая панель, прячется при прокрутке вниз и появляется при прокрутке вверх.

- Пять пунктов вместо трёх. Расстояние между текстами пунктов — новый токен `--nav-gap-dense: 2rem` (32) вместо `--nav-gap` (48), иначе на 1024 px не помещается. Расстояние от последнего пункта до кнопки оставить `--nav-gap`.
- Активный пункт: фон `var(--bg-3)`, `opacity: 1`, та же капсула, что у ховера сейчас (`--nav-link-py` / `--nav-link-px`, `--r-pill`). Переход фона — `var(--ease)`.
- `RollingText` на пунктах оставить.
- **Удалить временное красное свечение** у `.site-header.has-bg .site-header__inner` (`box-shadow … rgba(255,0,0,.15)`). Тени запрещены, фон `var(--bg)` остаётся.
- Кнопка не должна переноситься на две строки: `white-space: nowrap` на кнопке шапки. Проверь ширины 1440, 1280, 1024 и 800.

## 4. Телефон (≤ 767px) — вариант 3, нижняя панель

### Закрытое состояние
- **Сверху** остаётся только логотип: без бургера и без кнопки, фон прозрачный. Поведение «прячется при прокрутке вниз» сохраняется.
- **Снизу** — фиксированная тёмная панель-капсула, видна всегда:
  - позиция: `left/right: var(--s-12)`, `bottom: calc(var(--s-16) + env(safe-area-inset-bottom))`;
  - высота — новый токен `--dock-h: 3.75rem` (60), фон `var(--ink)`, радиус `var(--r-pill)`, внутренний отступ и gap — новый токен `--dock-pad` (6px);
  - слева кнопка «Меню»: иконка из двух линий и слово «Меню», фон `var(--ink-soft)`, текст белый, высота `calc(var(--dock-h) - 2 * var(--dock-pad))`, радиус `var(--r-pill)`;
  - справа кнопка «Обсудить задачу» со стрелкой-рикошетом (`RicochetArrow` / `BaseButton arrow`), фон `var(--white)`, текст `var(--ink)`, занимает остаток ширины.
- Вложенные скругления по правилу из `CLAUDE.md`: радиус внутренних кнопок равен радиусу панели минус отступ. Для капсул `--r-pill` это выполняется само.
- Панель не должна перекрывать конец страницы: добавь футеру на ≤767px нижний отступ `calc(var(--dock-h) + var(--s-32) + env(safe-area-inset-bottom))`.
- В `index.html` у meta viewport добавь `viewport-fit=cover`, иначе `env(safe-area-inset-bottom)` на iPhone не сработает.

### Открытое состояние (по нажатию «Меню»)
- **Затемнение** страницы: `rgba(29, 30, 34, .4)` — это `--ink` с прозрачностью, вынеси в токен `--overlay`. Без blur. Клик по затемнению закрывает меню.
- **Шторка снизу**: фон `var(--bg)`, радиус `var(--r-stage)` только сверху (27px), внутренние отступы `var(--s-12)`. Снизу запас под панель: `padding-bottom: calc(var(--dock-h) + var(--s-32) + env(safe-area-inset-bottom))`. Панель остаётся поверх шторки.
- Сверху шторки — «ручка»: 40×4, `var(--bg-3)`, по центру, отступ снизу `var(--s-16)`. Только декор, `aria-hidden="true"`.
- **Плитки** пунктов: сетка `1fr 1fr`, gap `var(--s-8)`.
  - Плитка: фон `var(--white)`, радиус `var(--r-card)`, высота 96px (токен `--tile-h: 6rem`), отступы `var(--s-12) var(--s-16)`.
  - Сверху номер `01`…`05`: `.caption`-размер, `var(--text-3)`.
  - Снизу название: `var(--f-head)`, 500, `var(--t-h3)`, трекинг отрицательный, как у `.h3`.
  - Пятая плитка (FAQ) на всю ширину (`grid-column: span 2`), ниже (72px), номер и название в одну строку слева.
  - Активная плитка (текущий блок из п. 2): фон `var(--ink)`, текст белый, номер `var(--accent)`.
- Под плитками — ряд из трёх кнопок мессенджеров на всю ширину (`flex: 1`), высота 56px, фон `var(--white)`, радиус `var(--r-card)`, иконки из `src/utils/messengers.js` (уже содержит svg). Ссылки внешние: `<a href target="_blank" rel="noopener">`, `aria-label` с названием мессенджера.
- Кнопка «Меню» в открытом состоянии меняет иконку на крестик (две линии поворачиваются, `transition: var(--ease)`), подпись остаётся «Меню», `aria-label` — «Закрыть меню».
- Анимация: шторка выезжает снизу (`transform: translateY(100%) → 0`), затемнение — `opacity 0 → 1`, обе через `var(--ease)`.
- Нажатие на плитку: закрыть меню, затем переход по ссылке. Прокрутку делает `scrollBehavior`.

### Доступность
- Кнопка «Меню»: `aria-controls="site-mobile-menu"`, `aria-expanded`.
- Шторка: `role="dialog"`, `aria-modal="true"`, `aria-label="Меню"`, `inert`, когда закрыта (как сейчас у `.mobile-menu`).
- `Esc` закрывает. При открытии фокус переходит на первую плитку, при закрытии возвращается на кнопку «Меню».
- `body { overflow: hidden }` на время открытия, при размонтировании снимать. Это уже есть, сохранить.
- `:focus-visible` на плитках и кнопках панели — `outline: 2px solid var(--ink); outline-offset: 2px`. На тёмной панели — `var(--white)`.

Старое полноэкранное мобильное меню (`.mobile-menu` с крестиком сверху) удалить целиком.

## 5. Новые токены (`tokens.css`, блок header)

```css
--nav-gap-dense: 2rem;    /* 32 — пять пунктов в шапке */
--dock-h:        3.75rem; /* 60 — нижняя панель на телефоне */
--dock-pad:      .375rem; /* 6 — отступ внутри панели */
--tile-h:        6rem;    /* 96 — плитка меню */
--tile-h-wide:   4.5rem;  /* 72 — широкая плитка FAQ */
--overlay:       rgba(29, 30, 34, .4);
```

Других чисел в стилях компонента быть не должно.

## 6. Проверка перед коммитом

1. `npm run build` без ошибок. Шапка пререндерится в HTML: ссылки на `#services` и другие блоки есть в исходном коде `dist/index.html`.
2. `npm run preview`, затем проверить:
   - 1440 / 1024 / 800: пять пунктов в одну строку, кнопка не переносится, при прокрутке подсвечивается нужный пункт, в hero и в блоке контактов подсветки нет;
   - со страницы услуги (`/services/infographics`) клик по «Отзывы» открывает главную на блоке отзывов, заголовок не прячется под шапкой;
   - 375 и 390: сверху только логотип, снизу панель; меню открывается и закрывается по кнопке, затемнению и `Esc`; активная плитка совпадает с блоком на экране; конец футера виден над панелью;
   - красного свечения нет.
3. Коммит: «Шапка: навигация по блокам главной, нижняя панель на телефоне».
