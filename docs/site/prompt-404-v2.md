## 1. Что на странице

Светлый фон `--bg`. Сверху логотип (ссылка на главную) и справа серая подпись «ошибка 404». В центре огромное «404», в котором каждая цифра в своём состоянии, как в редакторе:

| Цифра | Вид | Ярлык над ней |
|---|---|---|
| первая «4» | при входе заливается чёрным снизу вверх | «готово», синий |
| «0» | контур + **неподвижная** диагональная штриховка; по клику заливается | «в работе», оранжевый → после заливки «готово», синий |
| вторая «4» | только серый контур; курсор «Станислав» по кругу обводит её оранжевой линией | «в планах» серый → пока курсор рисует, «в работе» оранжевый; после обводки «почти готово» |

Через блок цифр проходят две тонкие синие горизонтальные линии во всю ширину окна (по верху и низу цифр), как направляющие. При входе выезжают слева.

Под цифрами — подсказка «нажмите на **0** — доделаем» (ноль оранжевый).

Ниже:
- `h1`: «Этой страницы нет. Или она ещё в работе»;
- текст: «Ссылка могла устареть, а могла опередить события: часть страниц я ещё собираю. Всё готовое — на главной.»;
- кнопки: `BaseButton` primary arrow «На главную» → `/`, secondary «Все услуги» → `{ path: '/', hash: '#services' }`.

На ПК `h1` слева, текст и кнопки справа (`1fr 1fr`, по нижнему краю). На ≤767 всё в одну колонку, кнопки на всю ширину.

После правки текстов — `npm run typo`. `useHead` оставить: `title: 'Страница не найдена — m/design'`, `robots: noindex`.

## 2. Клик по нулю

- 4 шага. Каждый клик (или Enter/пробел с клавиатуры) поднимает чёрную заливку нуля на четверть: `--lvl` 25 → 50 → 75 → 100%. Переход `clip-path` .6s `cubic-bezier(.22,1,.36,1)`.
- После первого клика подсказка «нажмите на 0» плавно исчезает.
- На 4-м клике:
  - ярлык нуля → «готово», синий;
  - через 0,5 с под цифрами появляется плашка «Готово! Но этой страницы всё равно нет» (белая, `--r-lg`);
  - кнопка «На главную» дважды мягко пульсирует (`scale(1.06)`, 0,9 с, 2 раза).
- Дальше ноль остаётся залитым, клики ничего не делают.
- Штриховка в нуле **не двигается** никогда.
- Ноль — `role="button"`, `tabindex="0"`, `aria-label="Доделать ноль"`, `:focus-visible` по правилу из `CLAUDE.md`. Блок цифр в целом `aria-hidden`, кроме этой кнопки. Для скринридера — `h1`.

## 3. Курсор обводит вторую «4»

Оранжевая стрелка курсора с плашкой «Станислав» (оранжевая, белый текст) едет по контуру второй «4», за ней остаётся оранжевая линия 3px. Цикл: обводка 4,2 с → пауза 1,6 с (курсор скрыт, ярлык «почти готово») → линия гаснет → заново. Первый старт через 2,2 с после загрузки.

Контур — ломаная в долях прямоугольника второй «4» (`getBoundingClientRect` её `span`); сняты с Gilroy Bold из макета:

```js
const CONTOUR = [[0.744, -0.033], [0.318, 0.530], [0.648, 0.530], [0.648, 0.326], [0.909, 0.326], [0.909, 0.530], [1.049, 0.530], [1.049, 0.690], [0.909, 0.690], [0.909, 0.842], [0.648, 0.842], [0.648, 0.690], [0.037, 0.690], [0.037, 0.530], [0.459, -0.033], [0.744, -0.033]]
```

Точки пересчитываются каждый кадр из текущего прямоугольника — так работает при любой ширине и после `resize`. Линия — `<svg>` с `<polyline>` на `position: fixed; inset: 0; pointer-events: none`. Если плашка «Станислав» не помещается справа (у края экрана на телефоне), она переезжает на левую сторону курсора.

Проверь на 1440 и 390, что линия ложится точно на контур цифры. Если шрифт сдвинул контур — подгони числа в `CONTOUR` и скажи мне.

`requestAnimationFrame` — один на страницу, пауза при `document.hidden`, отмена в `onUnmounted`.

## 4. Анимация входа

- Направляющие: `scaleX 0 → 1`, .9s, вторая с задержкой .15s.
- Первая «4»: контуром → заливка снизу вверх (`background-size` 0 → 100% у `background-clip: text`), 1,2 с, задержка .5s. Чтобы заливка не обрезалась по краям глифа, у `span` поля `padding: 40px 40px 10px 0; margin: -40px -40px -10px 0` (в токенах).
- Ярлыки появляются по очереди с 1,2 с через .25 с.
- `h1`, текст, кнопки поднимаются `y 24 → 0` с 1,4 с, шаг .1 с.
- Подсказка проявляется на 2,4 с.

Можно на GSAP (`onMounted`, очистка в `onUnmounted`) или CSS-анимациями, как в макете.

## 5. Стили и токены

Всё через токены. Новые — в `tokens.css` с комментарием «404»:

```css
--nf-digit:        min(28.75rem, 52vw);  /* 460px на ПК, по ширине экрана на телефоне */
--nf-stroke:       2px;                  /* контур цифр; 1.5px на ≤767 */
--nf-guide:        #3E7BFA;              /* синие направляющие и ярлык «готово» */
--nf-hatch:        #D9D5CF;              /* штриховка нуля */
--nf-outline:      #B8B4AE;              /* контур «в планах» */
```

- Цифры: `font: 700 var(--nf-digit)/0.8 var(--f-head); letter-spacing: -.04em`, по центру. Это намеренно, как и hero главной: огромная цифра, а не заголовок.
- Штриховка: `repeating-linear-gradient(135deg, var(--nf-hatch) 0 6px, transparent 6px 14px)` + `background-clip: text`. Это узор внутри цифры, а не декоративный градиент.
- Направляющие — 1px, `var(--nf-guide)`, `opacity .5`, выходят за контейнер на всю ширину окна.
- Ярлыки: `.caption`-размер 12px, `padding: 0 8px`, `border-radius: var(--r-sm)`; на ≤767 — 11px.
- Отступы страницы: ПК `40px 96px 64px`, ≤767 `20px 16px 24px` — токенами.
- На ПК блок текста прижат к низу экрана (`min-height: 100svh`, `margin-top: auto`). На ≤767 — сразу под цифрами, без пустоты.
