# Галерея работ: меньше скругление плиток и меньше подпись

Прочитай `CLAUDE.md`. Файл `src/components/service/WorksGallery.vue` (полноэкранная галерея), при необходимости `tokens.css`. Делать после `prompt-gallery-size-v1.md`.

## 1. Скругление плиток

Сейчас у `.ig__card` `border-radius: var(--r-card)` (20px). На маленькой плитке это слишком круглые углы.

- Заменить на `var(--r-lg)` (10px). Это тот же радиус, что у карточек стены работ на странице (`WorksWall.vue`, `.wall` → `var(--r-lg)`), так что галерея и стена станут одинаковыми.
- Если внутри плитки есть элементы со своим скруглением по краю (картинка, `.ig__in`), они не должны выглядывать за углы: у `.ig__card` уже стоит `overflow: hidden`, проверь, что это так.
- Просмотр одной работы (`.ig-view__…`) не трогать: там картинка крупная, радиус остаётся прежним.

## 2. Подпись на плитке

Плашка с названием сейчас слишком крупная для маленькой плитки.

- Перед правкой открой галерею в DevTools и посмотри фактический `font-size` у `.ig__tag`. Если он больше 12px, найди, что перебивает класс `.caption` (локальный стиль, `:deep`, наследование от `button`), и убери это. Типографику в компоненте не переопределяем, правило из `CLAUDE.md`.
- Если и при 12px подпись крупная, заведи токен `--gallery-tag: .6875rem; /* 11 — подпись на плитке галереи */` в блоке gallery в `tokens.css` и задай его только у `.ig__tag` (`font-size: var(--gallery-tag)`). Другие места не трогать.
- Плашка компактнее:
  - отступы внутри `var(--s-4) var(--s-8)` вместо `var(--s-4) var(--s-12)`;
  - отступ от края плитки `var(--s-8)` вместо `var(--s-12)` (`left`, `bottom`, и `max-width: calc(100% - 2 * var(--s-8))`);
  - одна строка с многоточием (`white-space: nowrap; overflow: hidden; text-overflow: ellipsis`). Если по `prompt-gallery-size-v1.md` категория уже скрыта, на плашке только название.
- Вес — 500, цвет `var(--ink)`, фон белый, `--r-pill`, как сейчас.

## Проверка

- 1440 и 375: углы плиток мягкие, но не «таблетки». Подпись мелкая, в одну строку, не перекрывает больше нижней пятой части плитки.
- Стена работ на странице услуги и галерея выглядят в одном стиле: радиус одинаковый.
- `npm run build` без ошибок. Коммит: «Галерея: радиус плиток 10px, компактная подпись».
