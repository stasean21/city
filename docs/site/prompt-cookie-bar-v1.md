Прочитай `CLAUDE.md`. Решение владельца: окно согласия с двумя галочками убрать, вместо него — простая плашка-уведомление. Яндекс.Метрика (с Вебвизором) запускается сразу при входе, не дожидаясь плашки. Политику поправить, чтобы она не противоречила сайту.

## 1. Плашка — новый `src/components/layout/CookieBar.vue`

Текст (дословно):

> Мы используем [cookies](/privacy), чтобы анализировать, как вы пользуетесь сайтом, и улучшать его

- «cookies» — `<RouterLink to="/privacy" class="text-link">` (внутренний переход — только RouterLink).
- Кнопка «Принять» — `BaseButton variant="primary"` (без `arrow`, без `roll`).
- Кнопка-крестик: круг 40px (токен `--cookie-x: 2.5rem`), фон `--bg-3`, цвет `--ink`, inline-SVG крестик 14×14 `stroke: currentColor`, `aria-label="Закрыть"`.
- «Принять» и крестик делают одно и то же: записать в `localStorage` ключ `cookie-notice` = `closed` и скрыть плашку. Больше она не появляется.
- Контейнер: `role="region"`, `aria-label="Уведомление о cookie"`. Фокус не перехватывать, фон не блокировать, Esc не обрабатывать — сайт под плашкой работает как обычно.

Вид (всё через токены, без чисел в `<style scoped>`):
- фон `--white`, тонкая рамка `var(--hairline) solid var(--border-soft)`, теней нет;
- радиус — вложенный: кнопка `--r-btn` + отступ `--s-12` → `calc(var(--r-btn) + var(--s-12))` (как `--header-r`);
- отступы: `--s-12` сверху/справа/снизу, `--s-24` слева; элементы в строку, `align-items: center`, gap `--s-12`;
- текст — класс `.small` (13px, `--text`), без своих размеров;
- **ПК (≥768):** `position: fixed`, слева внизу: `left: var(--s-24); bottom: var(--s-24)`, ширина `min(35rem, calc(100vw - 2 * var(--s-24)))` — токен `--cookie-w: 35rem`. Справа внизу остаётся ярлык подарка, они не пересекаются;
- **≤767:** `left/right: var(--s-12)`, над нижней панелью: `bottom: calc(var(--dock-h) + var(--s-16) + var(--s-12) + env(safe-area-inset-bottom))` (как у ярлыка подарка). Текст — на всю ширину сверху (`padding: 0 var(--s-8)`), под ним «Принять» растянута (`flex: 1`) и крестик справа. Отступы панели `--s-16` сверху, `--s-12` по бокам и снизу;
- `z-index` — выше контента, ниже окна подарка (модалки). Если в `tokens.css` есть шкала `z-index` — взять из неё, иначе добавить токен;
- появление: `opacity` + `y: 16→0`, `.4s`, через `<Transition>` (CSS), исчезновение — обратное. Reduced motion — без анимации (глобально в `base.css`).

Показ: только в браузере, после монтирования. При пререндере плашки в HTML нет (никакого мигания у тех, кто уже закрыл). На всех страницах, кроме 404 и `/styleguide`. На `/privacy` показывать можно — она ничего не закрывает.
