# Страница «Инфографика»: заменить работы-заглушки на 28 реальных работ

Прочитай `CLAUDE.md`. Работаем в основной папке проекта на `main`.

## Что меняем

Только `src/data/works.json`. Компоненты, стили и `banners.json` не трогать.

На странице `/services/infographics` работы берутся из `works.json` по фильтру `services.includes('infographics')` (`ServiceDetailView.vue`) и показываются в стене работ `WorksWall` с просмотром слайдов `SlidesLightbox`.

## Шаги

1. **Удали из `works.json` записи-заглушки:**
   - все записи, у которых в `services` есть `"infographics"` (компрессор, помада, гантель, конструктор, футболка, кресло, шуруповёрт);
   - все записи с пустым `"services": []` (наушники, кастрюля, поводок, кроссовки, чай, лендинг, CRM, дашборд и т. д.). Они нигде не показываются: страницы `/works` удалены.

   Записи `foto-*` (предметная съёмка) и `video-*` (видеообложки) **оставить как есть**: их заменим позже отдельно.
