# Hero: подсказка в строке задачи сама печатается и стирается

Прочитай `CLAUDE.md` (разделы «Анимации», «Доступность»). Файл: `src/components/sections/HeroSection.vue`.

Сейчас подсказка в поле просто сменяется каждые 4 секунды (`setInterval` + `:placeholder`). Нужно, чтобы она «печаталась»:
1. Текст набирается по одной букве, в конце строки мигает оранжевый курсор.
2. Готовая фраза держится 1,6 с.
3. Фраза стирается с конца, быстрее, чем набиралась.
4. Короткая пауза, затем набирается следующая фраза. И так по кругу.

Фразы те же: `PLACEHOLDERS`.

## Как сделать

Атрибут `placeholder` не умеет показывать курсор, поэтому рисуем «призрачный» текст поверх поля.

**Разметка.** Обернуть `<input>` в `<span class="hero__field">` с `position: relative; flex: 1; min-width: 0`. Внутри после input:

```vue
<span v-if="ghostOn" class="lead hero__ghost" aria-hidden="true">{{ typed }}<i class="hero__caret"></i></span>
```

**Стили.**
- `.hero__ghost`: `position: absolute; inset: 0; display: flex; align-items: center; pointer-events: none; color: var(--text); white-space: nowrap; overflow: hidden`. Шрифт тот же, что у поля: класс `.lead`.
- `.hero__caret`: `display: inline-block; width: 2px; height: 1.1em; margin-left: 2px; background: var(--accent); border-radius: 1px; animation: hero-caret 1s steps(1) infinite`.
- Пока буквы набираются или стираются, курсор не мигает: класс `is-typing` → `animation: none; opacity: 1`.
- `@keyframes hero-caret { 50% { opacity: 0 } }`.
- Если строка длиннее поля (на телефоне), текст обрезается справа, а не переносится.

**Состояние.** `typed` (строка), `ghostOn` = поле пустое **и** не в фокусе.
- Пока «призрак» виден, у input `placeholder=""`.
- В фокусе «призрак» скрыт, а у input `placeholder` = текущая полная фраза: человек видит пример, пока пишет своё.
- Если человек стёр свой текст и ушёл из поля, печать продолжается с новой фразы.

**Цикл** — на `setTimeout`, одна цепочка, без `setInterval`:

```js
const TYPE_MS = 55        // на букву при наборе (+ случайно до 35 мс, чтобы было живо)
const ERASE_MS = 22       // на букву при стирании
const HOLD_MS = 1600      // сколько держим готовую фразу
const GAP_MS = 350        // пауза между фразами
```

1. Набираем: `typed = phrase.slice(0, i)`, задержка `TYPE_MS + Math.random() * 35`. После пробела задержка чуть больше (+40 мс), так ритм выглядит естественнее.
2. Держим `HOLD_MS`.
3. Стираем по `ERASE_MS`.
4. Ждём `GAP_MS`, берём следующую фразу.

**Паузы.** Цепочка останавливается:
- пока hero не на экране (`IntersectionObserver` на `.hero__stage`);
- пока вкладка скрыта (`visibilitychange`);
- пока поле в фокусе или в нём есть текст.

Возобновляется с начала новой фразы.

**Reduced motion** (`prefers-reduced-motion: reduce`): никакой печати. В «призраке» стоит первая фраза целиком, курсор не мигает.

**SSR.** На сервере «призрак» сразу содержит первую фразу целиком: в HTML нет пустого поля, и при гидрации ничего не прыгает. Печать начинается в `onMounted` со стирания этой фразы.

**Очистка.** Все таймеры и наблюдатели снимаются в `onUnmounted`. Старые `nextPlaceholder` и `placeholderTimer` удалить.

**Доступность.** «Призрак» помечен `aria-hidden`. У поля остаётся `<label class="visually-hidden">Опишите задачу</label>`: скринридер не должен читать буквы по одной.

## Проверка

1. Главная, 1440: фраза набирается по буквам с оранжевым курсором, держится, стирается, набирается следующая. Ритм живой, не механический.
2. Клик в поле: «призрак» исчезает, внутри серым видна полная фраза-подсказка. Начали писать — подсказка ушла. Стёрли всё и кликнули мимо — печать продолжилась.
3. Прокрутить вниз и вернуться — печать продолжается, таймеры не множатся (после 5 переходов между страницами в Performance нет лишних таймеров).
4. 390: длинная фраза не переносится и не залезает под кнопку-стрелку.
5. Reduced motion — статичная первая фраза.
6. `npm run build` без ошибок, в `dist/index.html` в hero есть первая фраза.
7. Коммит: «Hero: подсказка в строке задачи печатается и стирается». Потом `git push`.
