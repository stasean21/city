# Подарок: ненавязчивая анимация ярлыка «Ваш подарок»

Прочитай `CLAUDE.md` (раздел «Анимации»). Делать после `prompt-gift-v1.md`. Файл `src/components/layout/GiftOffer.vue`, токены — `src/styles/tokens.css`. Анимации на CSS (`@keyframes`), GSAP не нужен. Без теней, свечений и градиентов.

## Идея

Ярлык в правом нижнем углу не мигает постоянно. Раз в ~15 секунд он «оживает» на пару секунд и снова успокаивается. Два приёма, по очереди:

### 1. «Встряхнуть подарок» — иконка
- Иконка подарка в ярлыке делает короткое покачивание: `rotate(0 → -12° → 10° → -6° → 0)`, `transform-origin: 50% 80%`, длительность 0.7 s, `ease-in-out`.
- Одновременно счётчик «4» делает один мягкий «вдох»: `scale(1 → 1.18 → 1)`, 0.7 s.
- Сама плашка ярлыка не двигается.

### 2. «Подсмотреть выгоду» — подпись
- Через ~15 секунд после первого покачивания текст «Ваш подарок» на 3 секунды сменяется одной из выгод, по кругу: «−20% на первые 3 заказа» → «7 дней правок бесплатно» → «Живая обложка за 0 ₽» → «−10% на сертификацию». Потом обратно «Ваш подарок».
- Смена текста — как прокрутка букв в меню: старый текст уходит вверх (`translateY(0 → -100%)`, `opacity → 0`), новый приходит снизу. 0.35 s, `var(--ease)`.
- Ширина ярлыка меняется плавно (`transition: width var(--ease)`; ширину считать по скрытому измерителю или `grid`-трюку, чтобы не было рывка).
- Тексты выгод брать из `gift.json` (`items[].value` + `items[].text`), короткие формулировки — новое поле `items[].short` в `gift.json`.

## Ритм и ограничения

- Цикл: покачивание → через 15 s подпись → через 15 s покачивание → … Интервал — токен в JS-константе `GIFT_NUDGE_MS = 15000` с комментарием.
- **Не больше 6 «оживлений» за визит**, потом ярлык просто стоит. Не надоедает.
- Первое оживление — через 3 s после того, как ярлык появился (после закрытия окна или при входе на сайт).
- Пауза, когда:
  - на ярлык навели мышь или он в фокусе (подпись в этот момент не меняется);
  - открыто окно подарка, галерея работ, просмотр слайдов или мобильное меню;
  - вкладка не активна (`document.visibilityState !== 'visible'`) — таймер не крутится в фоне.
- Наведение на ярлык (десктоп): плашка чуть приподнимается `translateY(-2px)`, фон `var(--ink-hover)`, `transition: var(--ease)`. Без тени.
- `prefers-reduced-motion: reduce`: никаких покачиваний и смены текста — ярлык статичный (глобальное правило в `base.css` уже гасит анимации; проверь, что таймер смены текста тоже не запускается).
- Таймеры создавать в `onMounted`, очищать в `onUnmounted` и при смене состояния ярлыка.

## Доступность

- Меняющийся текст подписи — `aria-hidden="true"`; у кнопки постоянный `aria-label="Ваш подарок: открыть"`. Скринридер не должен зачитывать каждую смену.
- Анимация не двигает ярлык по экрану и не меняет его положение — только содержимое.

## Проверка

1. Закрыть окно → ярлык в углу. Через ~3 s подарок покачивается, «4» делает вдох.
2. Ещё через ~15 s подпись на 3 s сменяется на «−20% на первые 3 заказа» и возвращается. Следующая смена — следующая выгода.
3. После 6 оживлений ярлык затихает до следующего визита.
4. Навести мышь — подпись не меняется, ярлык чуть приподнят.
5. Переключиться на другую вкладку на минуту и вернуться — не накопилось «пачки» анимаций.
6. Эмуляция `prefers-reduced-motion` — ярлык статичный.
7. `npm run build` без ошибок. Коммит: «Подарок: мягкая анимация ярлыка».
