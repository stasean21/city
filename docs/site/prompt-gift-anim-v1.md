# Подарок: ненавязчивая анимация ярлыка «Ваш подарок»

Прочитай `CLAUDE.md` (раздел «Анимации»). Делать после `prompt-gift-v1.md`. Файл `src/components/layout/GiftOffer.vue`, токены — `src/styles/tokens.css`. Анимации на CSS (`@keyframes`), GSAP не нужен. Без теней, свечений и градиентов.

## Идея

Ярлык в правом нижнем углу показывает подарки по очереди, как бегущая подсказка, и иногда встряхивает иконку.

### 1. Смена подписи — каждые 8 секунд, по кругу
- Порядок: «Ваш подарок» → «−20% на первые 3 заказа» → «7 дней правок бесплатно» → «Живая обложка за 0 ₽» → «−10% на сертификацию» → снова «Ваш подарок» → …
- Каждая подпись держится **8 секунд** (константа `GIFT_ROTATE_MS = 8000` с комментарием).
- Смена — как прокрутка букв в меню: старый текст уходит вверх (`translateY(0 → -100%)`, `opacity → 0`), новый приходит снизу. 0.35 s, `var(--ease)`.
- Ширина ярлыка меняется плавно (`transition: width var(--ease)`; ширину считать по скрытому измерителю или через `grid`-трюк, чтобы не было рывка).
- Короткие тексты — новое поле `items[].short` в `gift.json`:
  `"−20% на первые 3 заказа"`, `"7 дней правок бесплатно"`, `"Живая обложка за 0 ₽"`, `"−10% на сертификацию"`.
- Смена идёт **постоянно**: не останавливается от движения мыши по странице и от прокрутки. Лимита на число смен нет.

### 2. «Встряхнуть подарок» — иконка
- Каждый раз, когда подпись возвращается к «Ваш подарок», иконка подарка коротко покачивается: `rotate(0 → -12° → 10° → -6° → 0)`, `transform-origin: 50% 80%`, 0.7 s, `ease-in-out`, а счётчик «4» делает один мягкий «вдох» `scale(1 → 1.18 → 1)`.
- Плашка ярлыка при этом не двигается.

## Когда смена останавливается

- **Наведение мышью на ярлык или фокус с клавиатуры** → подпись сразу (с той же анимацией) становится **«Ваш подарок»** и стоит, пока курсор на ярлыке. Плашка чуть приподнимается `translateY(-2px)`, фон `var(--ink-hover)`, без тени. Увели курсор → через 8 секунд смена продолжается со следующей выгоды.
- Открыто окно подарка, галерея работ, просмотр слайдов или мобильное меню — смена на паузе.
- Вкладка не активна (`document.visibilityState !== 'visible'`) — таймер не крутится в фоне, при возврате продолжает с того же места (без «пачки» смен).
- `prefers-reduced-motion: reduce` — подпись статичная «Ваш подарок», без покачиваний; таймер не запускается.
- Таймеры создавать в `onMounted`, очищать в `onUnmounted` и при смене состояния ярлыка (ярлык → окно).

## Доступность

- Меняющийся текст подписи — `aria-hidden="true"`; у кнопки постоянный `aria-label="Ваш подарок: открыть"`. Скринридер не должен зачитывать каждую смену.
- Анимация не двигает ярлык по экрану и не меняет его положение — только содержимое.

## Проверка

1. Закрыть окно → ярлык «Ваш подарок». Через 8 s → «−20% на первые 3 заказа», ещё через 8 s → «7 дней правок бесплатно», … → снова «Ваш подарок» с покачиванием иконки.
2. Крутить страницу и водить мышью по странице — смена не останавливается.
3. Навести мышь на ярлык — сразу «Ваш подарок», стоит; увести — через 8 s следующая выгода.
4. Переключиться на другую вкладку на минуту и вернуться — смены не «догоняют» пачкой.
5. Эмуляция `prefers-reduced-motion` — ярлык статичный «Ваш подарок».
6. 375: ширина ярлыка при длинной подписи («−20% на первые 3 заказа») не вылезает за экран; если не помещается — на ≤ 767px использовать ещё более короткие формулировки: «−20% на 3 заказа», «7 дней правок», «Обложка за 0 ₽», «−10% сертификация».
7. `npm run build` без ошибок. Коммит: «Подарок: ярлык показывает выгоды каждые 8 секунд».
