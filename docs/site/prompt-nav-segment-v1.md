# Шапка: меню-переключатель (сегмент) вместо серых капсул

Прочитай `CLAUDE.md`. Файл `src/components/layout/TheHeader.vue`, при необходимости `tokens.css`. Меняется только десктопное меню (> 767px). Мобильную нижнюю панель, кнопку «Обсудить задачу», логотип, подсветку текущего блока (`useActiveSection`) и закрепление шапки на 10 секунд не трогать.

Макет — вариант **3** в `docs/site/header-mockup/6-nav-hover-varianty.png` и `nav-hover-mockup.html` (класс `.v3`) в ветке `claude/site-overview-setup-iskpz2`.

## Что сейчас не так

У каждого пункта своя серая капсула (`--bg-3`) на ховере и на активном пункте. Капсулы появляются и исчезают по одной, меню «прыгает».

## Как должно быть

1. **Капсула меню.** `.site-header__nav` — белая капсула: `background: var(--white)`, `border-radius: var(--r-pill)`, `padding: var(--s-4)`, `gap: 0`, `position: relative`. Между пунктами отступов нет, отступы дают паддинги ссылок.
2. **Пункты.** Паддинг `var(--nav-link-py) var(--nav-link-px)`, радиус `var(--r-pill)`, цвет `var(--text)`, **без фона ни в каком состоянии**. Убрать серый фон на `:hover` и у `.is-active`.
   - Ховер: цвет `var(--ink)`, `transition: color var(--ease)`. Прокатка букв `RollingText` остаётся.
   - Активный пункт: цвет `var(--white)`, сверху `z-index: 1`, чтобы текст был над «таблеткой».
3. **Одна скользящая «таблетка».** Внутри `nav` первым элементом `<span class="site-header__pill" aria-hidden="true"></span>`:
   - `position: absolute; top: var(--s-4); bottom: var(--s-4); left: 0; border-radius: var(--r-pill); background: var(--ink);`
   - ширина и положение — по активной ссылке: `width: <offsetWidth>px; transform: translateX(<offsetLeft>px)`;
   - `transition: transform var(--ease), width var(--ease), opacity var(--ease)`;
   - когда активного блока нет (первый экран, блок контактов, футер, другие страницы) — `opacity: 0`. Таблетка остаётся на месте последнего пункта и проявляется там, где появится следующий активный, без «прилёта» из угла: при переходе из `opacity: 0` сначала без анимации поставить её на новую ссылку, затем включить видимость.
4. **Расчёт положения** — функция `placePill()`:
   - вызывать при смене `activeHash` (`watch`), на `resize` (с `requestAnimationFrame`), после `document.fonts.ready` (ширина пунктов зависит от шрифта);
   - элементы ссылок брать через `ref` на массив (`:ref` в `v-for`), не через `querySelector` по классам;
   - всё в `onMounted`, слушатели снимать в `onUnmounted`. На сервере (SSG) не выполнять.
5. **Расстояния.** От капсулы до кнопки «Обсудить задачу» — `var(--nav-gap)`. Токен `--nav-gap-dense` больше не нужен для меню; если он нигде не используется, удалить.
6. **Фокус.** `:focus-visible` на ссылке: `outline: 2px solid var(--ink); outline-offset: 2px`. На активной ссылке поверх таблетки — `outline-color: var(--accent)`, чтобы было видно.
7. **Вложенные скругления.** У капсулы и таблетки `--r-pill`, правило из `CLAUDE.md` выполняется само.
8. Тени, градиенты, blur — нет.

## Проверка

- 1440 и 1024: на первом экране капсула белая, таблетки нет. Листаем: тёмная таблетка плавно переезжает «Услуги → Этапы работы → Отзывы → Обо мне → FAQ», текст активного пункта белый. В блоке контактов и в футере таблетка исчезает.
- Наведение на неактивный пункт — только текст темнеет и катятся буквы, без фона. Наведение на активный — ничего не ломается.
- Клик по пункту: плавная прокрутка, таблетка доезжает вместе со сменой блока.
- Смена ширины окна — таблетка остаётся ровно под своим пунктом.
- Со страницы услуги: таблетки нет. После перехода на главную к блоку она появляется на нужном пункте.
- `prefers-reduced-motion: reduce` — таблетка переставляется без анимации.
- ≤ 767px: меню скрыто, нижняя панель как была.
- `npm run build` без ошибок. Коммит: «Шапка: меню-переключатель со скользящей таблеткой».
