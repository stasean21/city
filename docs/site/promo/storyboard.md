# Промо m/design — 15 секунд, 120 BPM (30 долей по 0,5 с)

**Сквозной объект:** оранжевый слэш из логотипа «m/design». Это единственное место акцента на сайте. Он выходит из логотипа в шапке, по очереди становится лезвием, шторкой замены фона, полоской прогресса и затемнителем выдачи, а в конце возвращается в логотип.

**Бренд:** фон `#F6F4F2`, чёрный `#1D1E22`, акцент `#F59958` только на слэше и ключевом слове. Шрифт один — Gilroy.

**Переходы:** слэш разрастается за все четыре угла кадра, под ним меняется сцена, затем он сжимается в новую роль. Удар в звуке на 2,0 / 6,0 / 10,0 / 13,0 с, самый сильный — на 12,0 с.
