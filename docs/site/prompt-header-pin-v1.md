# Шапка не прячется 10 секунд после перехода к блоку

Прочитай `CLAUDE.md`. Делать **после** `prompt-fix-v1.md` и `prompt-header-v1.md`: правка ложится на новую шапку.

## Проблема

Клик по пункту меню прокручивает страницу вниз к блоку. Шапка видит прокрутку вниз и прячется (`isHidden = true` в `handleScroll`). Появляется она только при прокрутке вверх, поэтому сразу после перехода меню нет на экране.

## Нужно

После перехода к блоку шапка **закреплена на 10 секунд**: видна с фоном (`has-bg`), не прячется при любой прокрутке. Через 10 секунд работает как обычно: прячется при прокрутке вниз, появляется при прокрутке вверх.

## Как сделать — `src/components/layout/TheHeader.vue`

1. Константа в начале `<script setup>` с комментарием:
   ```js
   // сколько шапка остаётся на экране после перехода к блоку, мс
   const HEADER_PIN_MS = 10000
   ```
2. Состояние и таймер:
   ```js
   let pinnedUntil = 0
   let pinTimer = null

   function pinHeader() {
     pinnedUntil = Date.now() + HEADER_PIN_MS
     isHidden.value = false
     clearTimeout(pinTimer)
     // по истечении ничего не прячем сразу — следующая прокрутка решит сама
     pinTimer = setTimeout(() => { pinnedUntil = 0 }, HEADER_PIN_MS)
   }
   ```
3. В `handleScroll`, пока `Date.now() < pinnedUntil`: `isHidden.value = false`, `isScrolled` считать как обычно (чтобы был фон), обновить `lastScrollY` и выйти. Обновлять `lastScrollY` обязательно: иначе после окончания закрепления первое же движение посчитается как большой скачок.
4. Когда закреплять:
   - **любой переход с якорем.** `router.afterEach((to) => { if (to.hash) pinHeader() })`. Покрывает и клик на той же странице, и переход с другой страницы на `/#reviews`. Гвард снимать в `onUnmounted`;
   - **повторный клик по тому же пункту** (`route.hash === link.hash`). Навигации нет, `afterEach` не сработает, поэтому в обработчике клика, рядом с ручной прокруткой из `prompt-fix-v1.md`, тоже вызвать `pinHeader()`. Это касается пунктов шапки, плиток мобильного меню и кнопки «Обсудить задачу».
5. В `onUnmounted`: `clearTimeout(pinTimer)` и снять гвард `afterEach`.

## Телефон

Нижняя панель видна всегда, закрепление её не касается. Закрепляется верхняя шапка с логотипом, по тем же правилам.

## Не менять

- Порог 70px (`--header-h`), когда появляется фон.
- Поведение при обычной прокрутке без переходов: прячется вниз, появляется вверх.
- Открытое мобильное меню по-прежнему держит шапку видимой без таймера.

## Проверка

1. Главная, проскроллить чуть вниз, клик «FAQ»: страница доезжает до блока, шапка видна с фоном. Покрутить колесом вниз в течение 10 секунд — шапка остаётся. Через 10 секунд прокрутка вниз её прячет, вверх — показывает.
2. Со страницы `/services/infographics` клик «Отзывы»: после шторок шапка видна 10 секунд.
3. Два клика по «Отзывы» подряд с прокруткой между ними: таймер начинается заново со второго клика.
4. 375px: верхний логотип ведёт себя так же, нижняя панель всегда на месте.
5. `npm run build` без ошибок, коммит «Шапка: закрепление на 10 секунд после перехода к блоку».
