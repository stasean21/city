# Галерея работ: карточки меньше, на экране больше работ

Прочитай `CLAUDE.md`. Касается полноэкранной галереи всех работ (`WorksGallery.vue`, открывается со стены работ на странице услуги). Можно делать вместе с `prompt-gallery-drag-v1.md`.

## Что поменять

Размер плитки и зазор заданы токенами в `src/styles/tokens.css`, менять только их:

| Токен | Было | Стало |
|---|---|---|
| `--gallery-tile-w` (десктоп) | `15rem` /* 240 */ | `10.5rem` /* 168 */ |
| `--gallery-gap` (десктоп) | `var(--s-24)` | `var(--s-16)` |
| `--gallery-tile-w` (≤ 767px) | `11.25rem` /* 180 */ | `8.25rem` /* 132 */ |
| `--gallery-gap` (≤ 767px) | `var(--s-16)` | `var(--s-12)` |

Соотношение 3:4 и всё, что считается от `--cell-w` / `--cell-h`, пересчитается само. В `WorksGallery.vue` чисел не добавлять. Комментарии у токенов обновить под новые значения.

## Подпись на плитке

Сейчас на плитке белая плашка «Название · Категория», и на маленькой плитке она перестанет помещаться (уже сейчас «Конструктор Бетмобиль Конструкторы» обрезается).

- На плитке оставить **только название**, одной строкой с многоточием: `white-space: nowrap; overflow: hidden; text-overflow: ellipsis; max-width: 100%`.
- Категорию (`.ig__niche`) на плитке скрыть. В `aria-label` карточки и в просмотре работы она остаётся.
- Отступы плашки уменьшить до `var(--s-8)` по краям. Если внутренний отступ плашки был больше, взять ближайший меньший токен шкалы. Шрифт не менять, остаётся `.caption`.

## Проверка

- 1440×900: на экране помещается примерно 7–8 колонок и 3 ряда, раньше было около 5×2. Полотно тянется, края не видны, бесконечная прокрутка работает.
- 1024 и 375: плитки не налезают друг на друга, подписи не вылезают за плитку.
- Клик открывает просмотр работы, там название и категория.
- Картинки на маленьких плитках не размыты: файлы 900×1200, запаса хватает.
- `npm run build` без ошибок. Коммит: «Галерея: плитки меньше — больше работ на экране».
