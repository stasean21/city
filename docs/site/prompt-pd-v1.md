  Ссылка — `RouterLink`, подчёркнута акцентом;
- кнопки: `BaseButton` primary «Принять» и secondary «Только необходимые», размер `md`, без стрелок;
- появление: `opacity 0→1`, `y 16→0`, `.4s`, задержка ~0,8 с после загрузки, чтобы не спорить с анимацией hero. Исчезновение — обратно, `.3s`. При `prefers-reduced-motion` — без анимации;
- клавиатура: обе кнопки доступны по Tab, видимый `:focus-visible` по правилу `CLAUDE.md`. `role="region"`, `aria-label="Согласие на cookie"`. Фокус на плашку **не** переводить принудительно.

**Логика:**
- `localStorage`, ключ `cookie-consent`, значения `all` / `necessary`;
- все чтения и записи — в `try/catch`. Если хранилище недоступно — плашка показывается при каждом визите, Метрика не грузится, пока не нажали «Принять» в этом визите;
- при загрузке: `all` → грузим Метрику, плашку не показываем; `necessary` → не грузим, не показываем; ничего → показываем плашку;
- «Принять» → записать `all`, скрыть плашку, загрузить Метрику **без перезагрузки**;
- «Только необходимые» → записать `necessary`, скрыть. Метрику не грузить;
- `GiftOffer`: пока плашка на экране, подарок не открывается сам по таймеру (если такой авто-показ есть). Ярлык — как описано выше.

**Метрика** — `src/utils/metrika.js`:
- `loadMetrika()` — идемпотентно (второй вызов ничего не делает) добавляет `https://mc.yandex.ru/metrika/tag.js` и вызывает:
  ```js
  ym(108640080, 'init', { defer: true, clickmap: true, trackLinks: true, accurateTrackBounce: true, webvisor: false })
  ```
  затем `ym(108640080, 'hit', location.href)` для текущей страницы;
- **`webvisor: false`** — Вебвизор записывает действия посетителя, а в политике (п. 5.1) он не описан. Включать только после того, как я обновлю текст;
- переходы между страницами без перезагрузки: `router.afterEach` → `ym(108640080, 'hit', url, { referer })`, только если Метрика загружена;
- никакого `<script>` Метрики и `<noscript><img src="mc.yandex.ru…">` в `index.html`: без согласия на `mc.yandex.ru` не должно уходить ни одного запроса;
- всё — только в браузере (`onMounted` / `typeof window`), чтобы не сломать пререндер.
