```
2.1. Файлы cookie — небольшие фрагменты данных, которые Сайт сохраняет в браузере пользователя.
```

**Какие данные сохраняются в браузере**
```
3.1. Технические данные. Сайт запоминает в браузере пользователя, что уведомление об использовании файлов cookie закрыто, чтобы не показывать его повторно. Эти данные не передаются Оператору и третьим лицам.

Его файлы cookie помогают понять, сколько человек посещает Сайт, какие страницы они просматривают и как ими пользуются. Сервис собирает: IP-адрес, данные файлов cookie, сведения о браузере и устройстве, время доступа, адреса посещённых страниц Сайта. С помощью технологии Вебвизор сервис также записывает действия пользователя на страницах Сайта: прокрутку, нажатия и перемещения курсора.

```
