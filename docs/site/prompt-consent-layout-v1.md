# Страница «Согласие» — в том же оформлении, что и политика

Прочитай `CLAUDE.md`. Страница `/consent` сейчас — одна колонка текста. Делаем её как `/privacy`: слева «Содержание», справа текст с разделами.

Макет — ветка `claude/site-overview-setup-iskpz2`: `docs/site/legal-mockup/consent2-pc.png`, `consent2-mob.png` (исходник `index.html?v=consent2`).

## Что сделать

1. Вынести вёрстку документа из `PrivacyView.vue` в общий компонент `src/components/legal/LegalDocument.vue`:
   - пилюля «← На главную»;
   - `h1`;
   - необязательная строка под заголовком (у политики — «Дата редакции…»);
   - колонка «Содержание» со sticky, подсветкой активного раздела и плавным переходом к якорю;
   - разделы с оранжевыми номерами, ссылкой «#» и абзацами;
   - мобильная версия (содержание свёрнуто до 4 пунктов, «Показать все»).

   `PrivacyView.vue` перевести на этот компонент. Внешне политика **не меняется**.
2. `ConsentView.vue` — на том же компоненте. Данные — `src/data/legal/consent.js`:
   - **вступительный абзац** («Отмечая соответствующий чекбокс…») — над первым разделом, без номера и без пункта в «Содержании»;
   - **7 разделов**, по одному на пункт текста. Заголовки нужны только для навигации и в юридический текст не входят:
     1. Цель обработки
     2. Перечень персональных данных
     3. Перечень действий
     4. Способ обработки
     5. Срок действия согласия
     6. Отзыв согласия
     7. Ознакомление с Политикой
   - под каждым заголовком — пункт **дословно**, вместе с номером: «1. Цель обработки: …», «2. Перечень…» и т. д.;
   - якоря `id="punkt-1"` … `id="punkt-7"`.
3. Строки под заголовком у согласия **нет**: даты редакции в тексте согласия нет, не добавлять. Блока реквизитов в конце тоже нет: в тексте согласия его нет.
4. Текст согласия не менять: ни слова, кроме неразрывных пробелов от `npm run typo`. Сверить с текущим `ConsentView.vue` / промптом `prompt-pd-v2.md`.
5. Окно согласия на `/consent` по-прежнему не показывается.
