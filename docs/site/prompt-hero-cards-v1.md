# Первый экран услуги: три карточки выбираются полем `hero`

Прочитай `CLAUDE.md`. Файлы: `src/components/service/ServiceHero.vue`, `src/data/works.json`.

Сейчас три карточки на первом экране страницы услуги берутся как `works.slice(0, 3)`, то есть первые три работы по `order`: 1-я — по центру, 2-я — слева, 3-я — справа. Нужно выбирать их отдельно и не трогать порядок работ в стене и галерее.

## 1. Поле `hero` в `works.json`

У работы может быть необязательное поле `"hero": 1 | 2 | 3`:
- `1` — по центру, спереди (`is-center`);
- `2` — слева (`is-left`);
- `3` — справа (`is-right`).

Проставь его трём работам инфографики. Поле `order` у них **не менять**:

| slug | hero |
|---|---|
| `ig-bodi-zhenskoe` (Боди) | 1 |
| `ig-apelsinovye-palochki` (Апельсиновые палочки) | 2 |
| `ig-konstruktor-adidas` (Конструктор Adidas) | 3 |

## 2. `ServiceHero.vue`

```js
// карточки первого экрана: отмеченные полем hero (1 — центр, 2 — слева, 3 — справа),
// иначе — первые три по order, как раньше
const fanWorks = computed(() => {
  const picked = props.works.filter((w) => w.hero).sort((a, b) => a.hero - b.hero)
  return (picked.length ? picked : props.works).slice(0, 3)
})
```

В шаблоне заменить `works.slice(0, 3)` на `fanWorks`. Раскладка по местам `['center', 'left', 'right'][i]` остаётся.

На других услугах поля `hero` нет, поэтому у них всё остаётся как было.

## 3. Проверка

- `/services/infographics`: по центру «Боди», слева «Апельсиновые палочки», справа «Конструктор Adidas».
- Стена работ и галерея начинаются, как раньше, с апельсиновых палочек: `order` не менялся.
- Страницы предметной съёмки и видеообложек не изменились.
- `npm run build` без ошибок. Коммит: «Первый экран услуги: карточки выбираются полем hero».
