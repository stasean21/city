  "title": "…",
  "description": "…"

## 5. alt у картинок работ

Сейчас в собранном HTML у многих картинок `alt=""`: на инфографике 58 из 87, на видеообложках 20 из 22, на предметке 12 из 23. Пройди по `src/components` (`WorksWall`, `WorksGallery`, `PhotoRows`, `PhotoFan`, `VideoFan`, `VideoFeed`, `VideoReel`, `ServiceHero`, `CardStories`/`CardScenes`, `ReviewsWall`, `AboutSwitch` и другие с `<img`) и раздели картинки на два вида:

- **Содержательные** — работа показана как работа: обложка в стене, слайд в галерее, кадр в процессе. Им осмысленный `alt` из данных:
  - инфографика: `«Инфографика для карточки товара: ${work.title}»`, для слайдов галереи — `«${work.title} — слайд ${n} из ${total}»`;
  - предметная съёмка: `«Предметная съёмка с помощью ИИ: ${work.title}»`;
  - видеообложки (постер): `«Видеообложка для карточки: ${work.title}»`;
  - процесс купальника (`CardScenes`): по смыслу кадра — «Исходное фото купальника на белом фоне», «Модель в купальнике, сгенерированная ИИ», «Готовый главный слайд карточки купальника» и т. п.;
  - фото в «Обо мне» — `«Станислав Мунтяну, дизайнер»`.
- **Декоративные** — дубли для бесшовной ленты, размытые соседи в «Заметна в выдаче», повторные копии в анимации, фон. Им оставить `alt=""` и добавить `aria-hidden="true"`, если его ещё нет.

Правила из `CLAUDE.md` («Доступность», «Изображения») соблюдать. Не выдумывать то, чего нет на картинке: брать названия из `works.json`.

## 6. Разметка «кто я» для поисковиков (JSON-LD)

Невидимый блок `<script type="application/ld+json">`, как уже сделано у FAQ.

**На главной** — `ProfessionalService`:

```json
{
  "@context": "https://schema.org",
  "@type": "ProfessionalService",
  "name": "m/design",
  "url": "https://muntyanu-design.ru/",
  "image": "<OG_HOME>",
  "description": "<meta description главной>",
  "founder": { "@type": "Person", "name": "Станислав Мунтяну" },
  "areaServed": { "@type": "Country", "name": "Россия" },
  "sameAs": ["<ссылки на мессенджеры и соцсети из contacts.json>"],
  "hasOfferCatalog": {
    "@type": "OfferCatalog",
    "name": "Услуги",
    "itemListElement": [
      { "@type": "Offer", "itemOffered": { "@type": "Service", "name": "<service.title>", "url": "<SITE_URL>/services/<slug>" } }
    ]
  }
}
```

- `itemListElement` — только опубликованные услуги (без `draft`).
- `sameAs` — только реальные профили из `contacts.json` (Telegram, VK и т. п.). Телефон и WhatsApp туда не класть.
- Цены, рейтинги, отзывы, адрес **не добавлять**: их нет на сайте или они не подтверждены.

**На странице услуги** — `Service`:

```json
{
  "@context": "https://schema.org",
  "@type": "Service",
  "name": "<service.title>",
  "description": "<seo.description>",
  "url": "<SITE_URL>/services/<slug>",
  "provider": { "@type": "ProfessionalService", "name": "m/design", "url": "<SITE_URL>/" },
  "areaServed": { "@type": "Country", "name": "Россия" }
}
```

Данные строить из `services.json`, `contacts.json` и `site.js`. Руками ничего не дублировать.
