# Футер: тёмный «двойник» шапки — радиусы 15/27, квадратные мессенджеры

Прочитай `CLAUDE.md` (разделы «Вложенные скругления», «Цвет», «Доступность»). Файлы: `src/components/layout/TheFooter.vue`, `src/styles/tokens.css`. Делать после `prompt-header-panel-v1.md`. Этот промпт **заменяет** внешний вид из `prompt-footer-v1.md`, состав остаётся тот же.

Макет — вариант **1** в `docs/site/footer-mockup/footer-v2-1-2-3.png` и `footer-v2.html` (класс `.f1`) в ветке `claude/site-overview-setup-iskpz2`.

## Что остаётся как есть

- Тёмная плавающая карточка (`var(--ink)`), её внешние отступы и место на странице.
- Состав: логотип, пять пунктов меню (общий список с шапкой), почта `design@muntyanu.ru`, мессенджеры Telegram / WhatsApp / VK / Max (белые mono-иконки), реквизиты, «Политика конфиденциальности», «Наверх».
- Ссылки, `toTop()`, плавная прокрутка к блокам, нижний отступ под мобильную панель.

## 1. Токены

```css
/* футер: элементы r-btn (15) внутри карточки с отступом 12 → радиус карточки 15 + 12 = 27 */
--footer-pad: var(--s-12);
```
У карточки `border-radius: calc(var(--r-btn) + var(--footer-pad))`. Это 27, как и текущий `--r-footer`: можно присвоить `--r-footer` эту формулу, чтобы правило было видно в коде.

## 2. Карточка

- Внутренний отступ `var(--footer-pad)` со всех сторон. Верхняя строка прижата к краям так же, как у шапки: кнопки отстоят от края карточки на 12px.
- Слева от логотипа `var(--s-24)`, как в шапке.

## 3. Верхняя строка (одна линия, `align-items: center`)

1. **Логотип** (`logo-dark.svg`), `margin-right: auto`.
2. **Меню** — пункты высотой как кнопка (те же вертикальные паддинги и `line-height`, что у `.btn`), по горизонтали `var(--nav-link-px)`, радиус `var(--r-btn)`. Цвет белый с `opacity: .65`. Ховер: `opacity: 1` и фон `var(--ink-soft)` той же формы, `transition: var(--ease)`. Активной подсветки в футере нет.
3. **Почта** — кнопка высотой 44 (`--footer-icon-btn`), радиус `var(--r-btn)`, фон `var(--ink-soft)`, иконка конверта `var(--accent)`, текст белый. Ховер — `var(--ink-hover)`.
4. **Мессенджеры** — **скруглённые квадраты** 44×44 вместо кругов: `border-radius: var(--r-btn)`, фон `var(--ink-soft)`, иконка `item.mono` белая, `--footer-icon` (20). Ховер — `var(--ink-hover)`.

Зазоры: между меню, почтой и квадратами `var(--s-16)`, между квадратами `var(--s-8)`.

## 4. Нижняя строка

- Разделитель сверху `1px solid` — токен линии на тёмном (`--border-dark` из `prompt-footer-v1.md`, если он заведён). Отступы строки `var(--s-20) var(--s-24) var(--s-24)`.
- Слева: `© {год} m/design · ИП Мунтяну Станислав · ИНН 366609497266`, `.caption`, `var(--text-3)`.
- Справа: «Политика конфиденциальности» — текстовая кнопка, ховер `var(--ink-soft)` с радиусом `var(--r-btn)`; «Наверх» — кнопка высотой 36, фон `var(--ink-soft)`, радиус `var(--r-btn)`, стрелка вверх SVG.

## 5. Телефон (≤ 767px)

- Карточка: отступы `var(--footer-pad)`, радиус по той же формуле.
- В столбик: логотип → меню переносом (без капсул, ховера на тач-устройствах нет) → почта на всю ширину → четыре квадрата в ряд → разделитель → реквизиты → «Политика» и «Наверх» в одну строку.
- Квадраты мессенджеров 44×44, радиус 15. В ряд помещаются на 360px.

## 6. Проверка

- 1440 / 1024: всё верхнее в одну строку; кнопки почты, квадраты и пункты одной высоты; отступ от последнего квадрата до края карточки 12px.
- Радиусы: внутри всё 15, карточка 27. Кругов больше нет.
- 375 / 360: ничего не вылезает, конец футера виден над нижней панелью.
- `npm run build` без ошибок. Коммит: «Футер: двойник шапки — радиусы 15/27, квадратные мессенджеры».
