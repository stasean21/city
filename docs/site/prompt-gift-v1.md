# Подарок к первому заказу: окно по центру через 10 секунд, при закрытии — ярлык «Ваш подарок» в правом нижнем углу

Прочитай `CLAUDE.md` (разделы «Цвет», «Вложенные скругления», «Анимации», «Доступность»). Новые файлы: `src/components/layout/GiftOffer.vue`, `src/data/gift.json`. Подключение — `src/App.vue`.

Макеты (ветка `claude/site-overview-setup-iskpz2`, папка `docs/site/gift-mockup/`): окно — `2-okno-po-centru.png` / `g2.html`, свёрнутый ярлык — `4-svernuto-vash-podarok.png` / `g4.html`.

## 1. Данные — `src/data/gift.json`

```json
{
  "pill": "Подарок к первому заказу",
  "title": "Один заказ — четыре выгоды",
  "lead": "Напишите слово «подарок» в любой мессенджер — всё это добавлю к вашему первому заказу.",
  "items": [
    { "value": "−20%", "text": "на первые 3 заказа" },
    { "value": "7 дней", "text": "правок бесплатно" },
    { "value": "0 ₽", "text": "живая обложка — главный слайд в движении" },
    { "value": "−10%", "text": "на сертификацию у партнёра" }
  ],
  "cta": "Забрать подарок",
  "later": "Не сейчас",
  "note": "Срок акции ограничен",
  "tab": "Ваш подарок"
}
```

## 2. Поведение

Три состояния: `hidden` → `open` (окно) → `tab` (ярлык).

- **Первое появление:** через **10 секунд** после первой загрузки сайта в этой вкладке. Отсчёт идёт один раз за визит: переходы между страницами его не сбрасывают и окно повторно не вызывают.
- **Закрыть** (крестик, «Не сейчас», клик по затемнению, `Esc`) → окно сворачивается в **ярлык «Ваш подарок»** в правом нижнем углу. Окно больше само не открывается — ни в этом визите, ни в следующих.
- **Ярлык** виден всегда, на всех страницах, пока не открыт снова. Клик по ярлыку → снова окно (сразу, без задержки).
- **«Забрать подарок»** → закрыть окно (в ярлык) и перейти к блоку «Обсудим задачу?»: `{ path: route.path, hash: '#contact' }` (блок есть и на главной, и на страницах услуг). Плавная прокрутка, без загрузочного экрана — как в `prompt-fix-v1.md`.
- **Запоминание:** `localStorage` ключ `gift-state` = `"tab"` после первого закрытия/«Забрать». При следующем визите сразу показывается ярлык, окно само не всплывает. Чтение и запись — в `try/catch`: если хранилище недоступно, ведём себя как при первом визите.
- **Где не показывать:** страница 404 (`route.name === 'not-found'`) и `/styleguide`. Подключить в `App.vue` рядом с шапкой/футером под тем же условием `chrome`.
- **SSR:** весь код таймера и хранилища — в `onMounted`; в пререндер компонент не выводит ничего (ни окна, ни ярлыка), чтобы не мигало до гидрации. Таймер очищать в `onUnmounted`.
- Не показывать окно поверх открытой галереи работ / просмотра слайдов / мобильного меню: если что-то из них открыто, когда сработал таймер, отложить показ до их закрытия.

## 3. Окно (`open`)

- Затемнение `var(--overlay)` (токен из промпта шапки; если его нет — завести `--overlay: rgba(29, 30, 34, .4)`), без blur.
- Окно по центру: ширина `min(47.5rem, calc(100vw - 2 * var(--gutter)))` (760) — вынести в токен `--gift-w`. Фон `var(--white)`, радиус: плитки внутри `--r-btn` (15) + отступ… окно `--r-footer` (27). Отступы `var(--s-36)` или ближайший токен шкалы.
- Сверху `.pill` с иконкой подарка (inline SVG, `currentColor`, цвет `var(--accent)`) и текстом `pill`.
- Заголовок `title` — `.h2`-размер из `base.css` (не задавать шрифт в компоненте), `lead` — `.lead`.
- **4 плитки** в ряд (`repeat(4, 1fr)`, gap `var(--s-8)`): фон `var(--bg)`, радиус `var(--r-btn)`, крупное значение (шрифт заголовков, 600) и подпись `.small`. **Первая плитка** тёмная (`var(--ink)`, текст белый/`--dark-text`) — как на 9-м слайде Авито.
- Низ: кнопка `BaseButton variant="primary" arrow` — `cta`; текстовая кнопка `later`; справа `.caption` — `note`.
- Крестик — квадрат 36×36, радиус как у плиток минус отступ не нужен: `var(--r-lg)`, фон `var(--bg)`, в правом верхнем углу.
- ≤ 767px: плитки `1fr 1fr`, окно на всю ширину с полями `--gutter`, кнопки в столбик на всю ширину, `note` под ними.

## 4. Ярлык (`tab`)

- `position: fixed; right: var(--s-24); bottom: var(--s-24);` на ≤ 767px — **над нижней панелью**: `bottom: calc(var(--dock-h) + var(--s-16) + var(--s-12) + env(safe-area-inset-bottom))`, `right: var(--s-12)`.
- Тёмная плашка: высота 52, радиус `var(--r-btn)`… (как кнопки), фон `var(--ink)`, текст белый `tab`, слева иконка подарка `var(--accent)`, справа счётчик «4» — маленькая капсула `var(--accent)` с текстом `var(--ink)`.
- `<button>` с `aria-label="Ваш подарок: открыть"`, `aria-haspopup="dialog"`.

## 5. Анимация (CSS, без GSAP)

- Появление окна: затемнение `opacity 0→1`, окно `opacity 0→1` и `translateY(24px)→0`, `var(--ease)`.
- **Сворачивание в угол:** окно уменьшается и улетает к ярлыку — `transform-origin: bottom right`, `scale(1)→scale(.2)` + `opacity→0` + сдвиг к правому нижнему углу; одновременно ярлык въезжает `translateY(16px)→0`, `opacity 0→1`. Длительность ~0.4 s, `var(--ease)`.
- Открытие из ярлыка — обратно (из угла).
- `prefers-reduced-motion` — без движения (глобально уже отключено).

## 6. Доступность

- Окно: `role="dialog"`, `aria-modal="true"`, `aria-labelledby` на заголовок. При открытии фокус на кнопку `cta`; Tab циклится внутри окна; при закрытии фокус переходит на ярлык.
- `body { overflow: hidden }` на время окна, снимать при закрытии и размонтировании.
- `:focus-visible` — `outline: 2px solid var(--ink); outline-offset: 2px` (на тёмных элементах — `var(--white)`).

## 7. Проверка

1. Чистый `localStorage`, открыть главную: через 10 секунд окно. Перейти на другую страницу до 10 секунд — окно всё равно появится один раз, без повторного отсчёта с нуля.
2. Крестик / «Не сейчас» / затемнение / `Esc` → окно улетает в правый нижний угол, там «Ваш подарок 4». Клик → окно снова.
3. «Забрать подарок» → ярлык + плавная прокрутка к «Обсудим задачу?».
4. Перезагрузка страницы → окно не всплывает, сразу ярлык.
5. 375: окно читается, плитки 2×2; ярлык над нижней панелью, ничего не перекрывает.
6. 404 и `/styleguide` — ни окна, ни ярлыка.
7. `npm run build` без ошибок; в `dist/*.html` нет разметки окна (компонент только клиентский).
8. Коммит: «Подарок к первому заказу: окно через 10 с, ярлык в углу».
